# 界面行：任务、道具卡、场景抬头

语料里有一层不属于任何说话人的文字：任务日志、道具卡、场景抬头、解锁思维。它们单独成行，行首是类型名，后面直接跟内容，不加粗、不进引用块、不加方括号。数字由 `evals/ui_stats.py` 算出，口径是第 340 行之后。

| 类型               | 条数    | 形态                              |
| ------------------ | ------- | --------------------------------- |
| 新任务 / 任务完成  | 117/116 | `新任务:找到另一只鞋`             |
| 获得道具（含衣物） | 180     | 名称一行，描述 2–4 句，可带属性行 |
| 属性行             | 102     | `+1 技能:短评`，只挂在衣物卡上    |
| 场景抬头           | 228     | `Day1 8am 褴褛飞旋 二楼阳台`      |
| 解锁思维           | 53      | `解锁思维:名字`                   |

语料里没有方括号行，也没有挂在思维或事件上的属性变化。

## 新任务

任务行是语料里唯一的派活位置：思维阁解答不派活，具体的下一步写成一条任务。

- **句型**：祈使 84%，名词短语 12%（「堵车之谜」（行 22953）），问句 4%。中位 8 字，p75 10 字。动词加一个看得见的对象，不带理由、时限和副词。
- **位置**：前一行是「你」的 50%，是旁白的 29%。典型走法是你先用自己的话说出打算，任务行把它改写成更干的版本，下一拍世界照常往下走：「我应该去把鞋拿回来。」之后是「新任务:找到另一只鞋」（行 410），再下一行是破窗户灌进冷风。任务行之后接 NPC 或金的 66%，接技能 12%，没有人解释这条任务。
- **轻重并列**：日志把案件和私事排在同一层。走访餐厅经理（行 1261）旁边是「找点酒喝」（行 1753），后者跟在主角承认自己是酒鬼那句之后。117 条里十几条是这种小而荒唐的私事（手工粗分）。
- **完成**：117 条里 111 条后来有同名的「任务完成」，前一行多是旁白或你。场景当场解决了一件事时，用同名任务完成收住它。

本技能的写法：

1. 非短戏默认写一条新任务，内容是这个人在现实里真正要做的下一步。写虚构人物时是那个人物的下一步。
2. 动词和对象取自本篇已经出现的人、物和事，读者照着做不会出错：技术步骤、流程、价格和时间都要对，拿不准就写得更粗，不编具体数字。
3. 任务行放在场景中段你拿定主意的那一拍：先让「你」用自己的口气说出打算，再出任务行，之后世界至少再走几拍，事情照常往下发生。场景不解释任务，技能也不为它背书。
4. 需要笑点时，可以另加一条小而荒唐的私事任务，与正事并列，不加评论。

## 道具卡

用户拿到、穿上或打量一件东西时用。180 张卡里 42% 带描述，其余只有名称，下一行直接回到对话。

- **名称**：中位 7 字，具体到型号或来历，7% 带价格（`价格 ✣0.5`）。
- **描述**：中位 72 字、3 句。37% 以“这”起句，一半含“你”，三分之一有今昔或转折：先说它本来是什么，再说它现在落到你手里成了什么，如「普通的喇叭裤一般是小喇叭」之后是尿渍和精斑（行 356–358）。描述写物件，不写人物心理。
- **属性行**：102 行全部在衣物和穿戴品卡上，每张卡 1–3 行。数值 ±1 占 91%。短评中位 5 字，是名词短语，几乎不用句号和叹号，说的是穿上它为什么加或减：「讨厌的气味」（行 456）、「荒谬的高跟」（行 603）。至少 18 张卡一加一减，减的那条多半是笑点。

本技能的写法：道具卡只给真正进了你手里的东西，每篇至多一张；属性行只用于衣物和穿戴品，技能名用 24 技能的中文名。

## 场景抬头

格式是 `Day天数 时刻 区域 具体处`，79% 的地点分两级。37% 的抬头后跟 1–4 行无标签短句（每行中位 18 字），写此地的天气、气味或一块告示牌；随后第一个开口的多半是当地的人或物（55%），其次是你（15%）和技能（14%）。

本技能的写法：可选，只在时间和地点本身会改变选择时写（截止时间、营业时间、某个只在那里的人）。写了就不必在正文里再报时。

## 解锁思维

`解锁思维:名字` 落在对话中途，前一行多是你（47%）或旁白，后一行多是技能（34%）。本技能的思维阁块照旧写在场景之后，写法见 [思维阁](thought-cabinet.md)；需要游戏感时可在对话里念头成形的那一拍加这一行，名字与块的标题一致。

## 收尾

场景停在下一个动作或世界的最后一句话上（见 [风格总论](style.md)「悲伤与严肃的写法」）。本篇当场解决了的事可以用任务完成作最后一行；新任务不作结尾，否则它和场景、思维阁各收一次尾。不写方括号行。
