# HTML 输出

用户要网页版或可分享页面时读。默认交付 Markdown；这里把同一场戏排成一个暗色单页。

## 做法

1. 复制 `../assets/templates/narrative.html` 到输出位置，只填 `<body>`（内容写在 `<div class="wrap">` 里），再替换 `<head>` 里的 `{{标题}}` 和 `{{一句话引子}}`，CSS 保持原样。模板用系统字体、没有外链，单个文件就能离线打开或发送。
2. 按「速查」把 Markdown 稿逐行换成标签。每条发言一个段落：名字放进对应的 span，后接空格、破折号、空格和正文，写法见下表。
3. 每个技能名加属性 class，查「技能属性」。
4. 要分享图片就导整页长图 PNG。PDF 的 A4 分页会把一句话和它的接话切到两页。

## 速查

| Markdown 稿                           | HTML                                                                                              |
| ------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 技能 `**技能名**【成功】 — 内容`      | `<p class="s"><span class="sk int">技能名</span><span class="ck">【成功】</span> — 内容</p>`      |
| 五感发达 `**五感发达**(视觉)【成功】` | 感官写进名字：`<span class="sk mot">五感发达(视觉)</span>`                                        |
| 你 `> **你** — 内容`                  | `<p class="you"><span class="who">你</span> — 内容</p>`                                           |
| 人物 `称呼 — “引语”动作。`            | `<p class="npc"><span class="who">称呼</span> — “引语”动作。</p>`                                 |
| 物品与场所 `*物品名* — 内容`          | `<p class="obj"><span class="on">物品名</span> — 内容</p>`                                        |
| 古老的爬虫脑、边缘系统                | `<p class="reptile"><span class="sk rep">古老的爬虫脑</span> — 内容</p>`                          |
| 强调 `*词*`                           | `<em>词</em>`                                                                                     |
| 没有名字的旁白                        | `<p class="scene">`，开场那段加 `lead`                                                            |
| 场景抬头 `Day1 8am 区域 具体处`       | `<span class="timestamp">`                                                                        |
| 物证、官方引文                        | `<div class="doc-quote">`，出处放 `<span class="src">`                                            |
| 分隔 `---`                            | `<hr class="sep">`；重大转折用 `<hr class="beat">`                                                |
| 新任务、任务完成                      | `<p class="ui"><span class="k">新任务</span>内容</p>`                                             |
| 道具卡                                | `<div class="card">`：名称行 `<p class="ui">`，描述 `<p>`，属性行 `<p class="mod">`               |
| 信息表                                | `<table>`，表头按本篇的事起名                                                                     |
| 思维阁                                | `<section class="tc">`：`<h2>思维阁</h2>`、`<h3>名字</h3>`，问题和解答前各一行 `<p class="tabs">` |
| 页头、页尾                            | `<header>` 里放 `.kicker`、`h1`、`.dek`、`.cast`、`.stamp`；页尾 `.colophon` 是属性色图例         |

检定标记【成功】【失败】共用一个 `.ck`，不写标记的技能行不加 `.ck`。页头 `.cast` 里的技能名同样带属性 class。思维阁的标题条只写名字；`.tabs` 里当前段落的标签包在 `<b>` 里，显示为反白页签。

## 技能属性

| 属性 | class | 技能                                                       |
| ---- | ----- | ---------------------------------------------------------- |
| 智力 | `int` | 逻辑思维、博学多闻、能说会道、故弄玄虚、标新立异、见微知著 |
| 精神 | `psy` | 平心定气、内陆帝国、通情达理、争强好胜、同舟共济、循循善诱 |
| 体格 | `fys` | 钢筋铁骨、坚忍不拔、强身健体、食髓知味、天人感应、疑神疑鬼 |
| 身手 | `mot` | 眼明手巧、五感发达、反应速度、鬼祟玲珑、能工巧匠、从容自若 |

分组照游戏角色表，与 `assets/raw.txt` 开头的属性分组一致。古老的爬虫脑和边缘系统不在这 24 个里，用 `rep`。

## 配色

取自游戏的是技能名的四种属性色：色相从游戏截图取，亮度调到在页面底色上对比度不低于 4.5。

其余是本技能的约定。名字灰白加粗、检定标记暗灰、续行悬挂缩进、思维阁的浅色标题条和「问题 / 解答」页签参照游戏对话框与思维阁界面，颜色为可读性提亮过。暗角底色、物品名斜体（对应 Markdown 的斜体）、爬虫脑的锈红名字、暗金界面行、道具卡和物证的细框、页头页尾由本技能自定。
