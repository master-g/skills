# 风格总论：语料里的走法

口径：开发语料第 340 行后解析 41368 条发言，去重 39927 条（技能 8784、你 14473、金 3918、其他 12752），由 `evals/corpus_stats.py` 重算。语料按分支排列，相邻不一定线性，序列数字因此偏高。排版约定见 [format.md](format.md)。短引只用来校准，成稿用本篇的物件和句式写。

## 叙述旁白

没有独立的旁白栏，叙述寄生在标签上：物品或场所名 — 句子，NPC 或金的标签下不带引号的句子。这类无引语记录 2546 条。305 个说话人里，150 个（至少两条）七成以上发言无引号，条数中位 7：物件和场所出场几拍就退场。吊人 143 条全无引号，只有 19.6% 含“我”，其余是验尸旁白。

- 人称：50.4% 含“你”，只有 12.3% 以“你”开头，他或她开头 9.5%。先写物件，再让你撞上它。
- 时间：“了”45%，“着”27%，“曾经/以前”0.7%，“将会”0.2%。写刚发生的事，不回望也不预告。
- 句长：每条中位 35 字、2 句；单句中位 15 字，p95 为 40。

从白描滑入评价走三步，中间不加连词：物理事实，落到你身上的后果，一句给物件态度或给你打分。「窗户同意了。它破碎的微笑冰冷而耀眼。」（行 413）紧接在“冷风灌入、脚趾蜷缩”之后（行 411）；「一开始感觉很好，然后就开始疼了。」（行 27644）。变体：旁白半路纠正自己，「我指的是腿，而不是靴子。」（行 15063）；或用会议口气描述拒绝合作的物件（行 6781）。

## NPC 发言形态

| 形态                   | 非金 NPC（12752） | 金（3918） |
| ---------------------- | ----------------- | ---------- |
| 只有引语               | 36.2%             | 40.3%      |
| 引语开头，后接动作     | 40.9%             | 43.2%      |
| 动作开头，后接引语     | 5.6%              | 8.0%       |
| 无引语，只有动作或旁白 | 17.3%             | 8.6%       |

默认让话先出来，动作跟在后面或夹在两段话之间。动作开头只留给比话重要的瞬间：停顿、递东西、拔枪。“他说/她说/说道/回答”类只占 2.5%，省略靠动作句自带主语；雷内 11.4% 是例外。

动作句有三种用途：指物（朝院子点头），转交话轮（转向你），反驳引语，如「“哈!没错。”他其实并没有笑。」（行 8584）。只装饰的动作删掉。主语多用身份描述（老兵、年轻人、圆胖的男人），和标签错开。金的旁白多以“警督”起句，一个动作一句（行 18257）。

动作开头高的是可见的人（鸟巢罗伊 15.3%，普莱桑斯 9.3%，莉娜 9.0%），低的是只闻其声或只顾说话的人（测颅先生 1.0%，弓箭手号 2.2%，坤诺 2.7%）。金的层级见 [special-voices.md](special-voices.md)。

任何位置带括号的 7.5%（引语后 4.5%，引语前 2.2%）。括号常见内容是转向金、低语、指向、点头、环顾，极少写心理；撒谎标记 18 条。裸句里 27.3% 是问句，29.6% 含“我”，46.6% 不含人称且不是问句，多为祈使动作（看向外面、敲门）。

引语后接 NPC 或金 89%，接技能 1%；裸句后接技能 42%。所以引语对外，裸句对内。全部选项 37.3% 含问号：主角的主要工作是问。超过 40 字只占 3.7%。

蠢选项是在严肃问题旁放一个身份宣言，下一拍让世界平淡地接住，如「“我是末日警探。”」（行 725）。“我是”开头只占 0.7%，稀少才好笑。诚实选项与蠢选项同题并列，用最平的词承认，长度中位 24–26 字，比普通引语长：「我不是超级明星。我是个垃圾。」（行 1010）。同题可做梯度：同一个名词排四档，从夸张到难堪（行 970–977），或三档身份（行 69299–69301）。

## 悲伤与严肃的写法

语料给过规则：「只是千万别说你明白他们的感受。你不明白。」（行 51164）。悲伤词很少：悲伤 0.36%，痛苦 0.32%，孤独 0.10%，绝望 0.09%，多由技能说出，当事人很少命名自己的感受。

- 把痛放到数字和程序上：主角和对方讨价还价分手年数，从 6 砍到 3，对方只重复同一句解释（行 69973–69980）。
- 让当事人说错话：半夜打电话，开口是「“你的声音让我想化成灰。”」（行 47703），对方刚醒，只认出是他。
- 让回应比痛小：濒死的主角连说长句，金只回「“坚持住!”」（行 64152）。反差在长度上，不在形容词。
- 技能不安慰，只报事实：「这不是他会引以为傲的东西，但事实就是如此。」（行 64623）。
- 对方接不住时不替他接：主角念出难堪的诗，朋友只有「“这个嘛......呃......”」（行 24362）。

收住的位置在下一个动作上：开门、走路、回案子。“我们走吧”全语料 50 行，传达死讯前也用它（行 51171）；争吵前金只说就到此为止，开门，冷风进来（行 53307）。不写感悟，不让人物总结这件事的意义。

## 比喻与意象

“像”族出现在 6.7% 的记录里（技能 9.0%）：就像 1.59%，仿佛 0.25%，如同/犹如/宛如 0.21%。对 130 条抽样人工分类（±5%）：不是比喻的“就像你说的”约 25%，器物与工业约 20%，人与职业约 18%，动物约 12%，自然约 8%，流行文化与舞台约 8%，身体医学约 6%，武器约 3%。

走法：喻体取自手边和说话人的行当，放句尾，不接解释。常用来把大东西拉小，把严肃的事拉低：尸体转动「如同串在烤肉串上的鸡肉」（行 5246）。

语料少见但仿写常见的（全语料条数）：手术刀 2、月光 3、星光 2、烛 2、钟摆 1、铁锈 3、蝴蝶 4、指节 5、心跳 6、玫瑰 6、尘埃 8、深渊 16。语料里的日常物是酒 690、门 653、烟 432、窗 282、鞋 134。先从场景已有的物件里找喻体。

## 语域混杂

一条发言通常只用一种语域，混杂靠相邻两拍撞出来，或一句高语域落到一个俗词上。

- 公文：验尸表逐项填写，主角卡在基本词上（行 6568–6590）。
- 学术：学派互相瞧不起，从不解释学派是什么（行 55478–55492）。
- 军语与政论：老兵把一生讲成路线错误（行 66804）。
- 广告：领带的出身写成品牌故事（行 64021）。
- 街头：第三人称和外号（行 7673）。
- 诗：天人感应和濒死场景（行 64145–64160）。

关键词粗计只比量级：军事 1.8%，公文 0.96%，学术 0.89%，广告 0.73%，街头呼语 2.05%。硬脏话是人物属性：NPC 3.2%，你 1.0%，技能 0.9%，金 0.3%；科顿艾尔 42%，坤诺 23%，提图斯 12%。技能里集中在疑神疑鬼和食髓知味。

## 检定呈现

技能行实际只有三种：【成功】、【失败】、无标记。全语料【成功】6734、【失败】240、【失败/成功】1；技能行 22.3% 无标记，其中 65% 是同一技能在 3 条内续说。难度档作为标记出现 0 次，反应速度[中等:失败 这种写法全语料 1 处（行 40972），括号错位，是提取残留。红白检定字样 0 次，大成功作为标记 0 次。

文本不标主动或被动，靠前一条判断。带标记的技能行前接“你”只有 254 条，其中失败约三分之二；其余前接 NPC、技能或金，是被动插话。所以【失败】的典型位置是你刚选了一个动作（70%）。

失败占带标记行 3.4%，约 29 次一失败，不必每场都有。按规则粗分：坏主意或抢话 29%（技能自信地给错建议，或话已出口），身体事故 27%，落空 24%，其他 20%。失败中位 38 字，比成功的 26 字长，15 字以内只有 6.4%；精神感官类失败中位 39 字。写完失败的过程，不靠一句短话了事。

- 坏主意：「这次一定会成功的，你已经排除了第一个*糟糕*的选项。」（行 16639）
- 抢话：「话语已经从你嘴里蹦出来了...」（行 710）
- 身体事故：「但切链钳却从你手中滑了出来。」（行 15198）
- 落空：「你没有任何线索。它只是一堵墙。」（行 10280）

失败后接你 100 条，接技能 93 条，有 84 条下一行是带【成功】的接应。

## 场景节拍与声部接力

记 N 其他人物或物件，Y 你，S 技能，K 金。三元序列前列：NYN 14.0%，YNY 12.5%，YNS 7.0%，SYN 6.6%，NSY 5.2%，YKY 3.5%，KYK 3.3%，SSY 3.1%。

| 当前 | 下一条                                   |
| ---- | ---------------------------------------- |
| 技能 | 你 57.0%，技能 25.6%，NPC 12.7%，金 4.8% |
| 你   | NPC 63.1%，金 17.5%，技能 10.2%，你 9.1% |
| NPC  | 你 50.9%，技能 29.7%，NPC 12.4%，金 7.0% |

连发技能 1 条 75.2%，2 条 18.2%，3 条以上 6.6%。每 10 条约 5 位说话人、2 条技能、4 条你。主体是对话，脑内是注释：你问，对方答，一个技能插一句，你据此再问。技能很少互相吵，多半在给你的下一句供料。

每拍只交一件新东西：技能给对方话里没有的东西（微表情、事实、冲动、坏主意），你给方向，NPC 给信息或拒绝。如果一条技能只评论气氛，删掉。同一技能紧接自己只有 131 处，你连发 1370 处，多是互斥分支（如行 502–504），不要写成连说。

## 译文腔

可以借的翻译腔，少量使用：反意尾句（不是吗 180、对吗 98、是吗 321），缓冲词（恐怕 96、似乎 388、好像 689、看起来 649），你知道的 138，某种 377，一种 716，呼语（兄弟 314、老兄 197、伙计 97、宝贝 72）。

语料里还有提取错误，别模仿：破折号写成“一一”或 `--`，車代替车，说到/说道混用，星号不成对，UI 字串和译注粘进正文。

## 质地校准

仿写最大的破绽是太典型：每条都功能齐全，读来像声部说明书的样本。下表是语料技能行的质地，右列是仿写常见的偏差：

| 指标                       | 语料 | 仿写常见偏差 |
| -------------------------- | ---- | ------------ |
| 字数中位                   | 29   | 偏长         |
| 单句台词                   | 36%  | 几乎没有     |
| 三句以上                   | 26%  | 偏多         |
| 指令起句                   | 5%   | 偏多         |
| 语气词（吧呢啊嘛）         | 13%  | 偏少         |
| 缓冲词（也许、好像、大概） | 16%  | 偏少         |
| 虚指（某种、这个、东西）   | 31%  | 偏少         |
| 连词（因为、不过、如果）   | 17%  | 偏少         |
| 含数字                     | 17%  | 偏多         |
| 比喻                       | 10%  | 偏少         |
| 省略号收尾                 | 10%  | 几乎没有     |

具体走法：

- **声部卡写的是它能做什么，不是每条都要做满。** 很多台词只完成半个动作：一句判断、一个反应、接半句话。多数台词写一两句就停。
- **留平淡的接话。** 语料里有不少没有新信息的回应和泛泛的认可，如「差不多吧。不过，至少你找到自己的鞋了。」（行 618）、「诚然，没有什么是*不可能*的。」（行 37037）。它们让后面的好句子显得不是刻意的。
- **让它说不准。** 原文常用“某种”“好像”“也许”，也常半路停住，如「她的手微微颤抖......」（行 52728）。别把每个观察都落成精确读数或可执行的线索。
- **用普通连词讲话。** 句子之间可以有“不过”“因为”“所以”，不必都是冷硬的并列短句。
- **少抖机灵。** 别让每条都以俏皮的转折收尾，一段里至多一两条。好笑多半来自局面，不来自这条台词的结尾。
- **让台词长在这个世界和这段对话里。** 技能行常带本世界的人名、地名或行话，且不加解释。写新世界时也一样：用本篇已有的名字和说法，别写成放到哪个故事都成立的通用句。
- **少用数字和小道具。** 精确的数量、型号、部位是仿写的习惯，语料里主要是见微知著、博学多闻的事。

校准不等于写差。一段里好句子和平常句子都要有。写完先看单句比例和字数中位，差得最远时优先调整。

## 跑偏写法

| 模式                   | 全部记录 | 技能  | 处理                         |
| ---------------------- | -------- | ----- | ---------------------------- |
| 不是 X，而是 Y         | 0.13%    | 0.27% | 一场最多一次，默认直接说 Y   |
| 三连同头排比           | 0.21%    | 0.34% | 改成一句具体的               |
| X 的是 Y，Z 的是 W     | 0.01%    | 0.01% | 删                           |
| 没有 A，没有 B，没有 C | 2 条     | 2 条  | 留一个最具体的               |
| A、B、C 三项列举       | 0.2%     |       | 换成一个物件                 |
| 长句后 6 字内收尾      | 0.43%    | 1.18% | 结尾留在信息上，不留在金句上 |
| 所有 X 都 Y            | 0.54%    | 0.66% | 落回这个人和这件事           |

其他可证伪的习惯：

- 句句金句：“生活就是”3 条，“世界就是”5 条。
- 抽象名词堆叠：真理 0.02%，尊严 0.04%，荒谬 0.06%，命运 0.07%，人生 0.10%，灵魂 0.20%。
- 全程脑内：技能只占发言 22%，你 37%，世界 42%。一段写成几个技能轮流独白，比例已经错了。
- 每句以“你”开头：技能行只有 10.3%。
- 一律不确定：也许/或许/可能 5.8%，一定/肯定 2.4%。技能经常下断言，而且常常断错。
- 碎句堆节奏：技能一条中位 2 句，单句中位 13 字，只有 1.8% 连着三个 6 字内短句。
