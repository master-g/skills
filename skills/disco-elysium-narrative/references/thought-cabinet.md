# 思维阁写法

《极乐迪斯科》中文语料共 53 条思维，比例分母都是 53。开口、转折、母题、安慰度为手工单标签，归类可商榷；长度和句尾由脚本算出。全部条目和取证说明在 `evals/thought-cabinet-entries.md`，写作时不用读。

## 名字的形状

名称中位 6 字，动词短语只有打扫房间、手指搭在弹射按钮上，其余是名词性短语。15 条含“的”，11 条含作品内专名。

| 形状       | 占比      | 怎样造                                   | 例                  |
| ---------- | --------- | ---------------------------------------- | ------------------- |
| 伪术语     | 14（26%） | 学科或器械的词缀配低俗、私人或错位的名词 | 粪便体积压缩机      |
| 身份标签   | 8（15%）  | 自封的类型，像简历上的污点               | 扭矩呆子            |
| 片语       | 8（15%）  | 像歌名，至少一个词落在可感的东西上       | 南向高速路          |
| 动作或小事 | 7（13%）  | 把琐事写成正事，或不解释                 | 又是一扇门          |
| 编制       | 6（11%）  | 给一个人的毛病配一个组织                 | 反物质特遣队        |
| 人名       | 5（9%）   | 姓名，可加一件难堪的事                   | 卡拉斯·马佐夫的自杀 |
| 器物       | 5（9%）   | 型号或具体物件，不解释用途               | 费尔韦瑟 T-500      |

语料里没有的烂名字（53 条为 0）：成长动词（学会、放下、原谅、接纳）；“X 的意义／力量”；“如何 X”“关于 X”；治愈、救赎、内心、灵魂一类词；带标点的整句。片语类最容易滑向两个抽象词相加。

## 问题的写法

| 开口类型                     | 占比      | 动作                                             | 例                     |
| ---------------------------- | --------- | ------------------------------------------------ | ---------------------- |
| 接话：像在答复没写出来的争论 | 11（21%） | 顺着那段对话应一声再往下说，顶回去的少；主题后露 | 行 1030、9118、38040   |
| 感知：报告看见听见的东西     | 9（17%）  | 你被当成观察员                                   | 行 11355、12340、23953 |
| 通论：知识或普遍说法         | 9（17%）  | 前半像百科，后半漏气                             | 行 7975、6364、13059   |
| 画面：清单或无人场景         | 7（13%）  | 先给物，人后到                                   | 行 22975、24953、30716 |
| 异动：体内有东西在动         | 6（11%）  | 不知名的东西先开始                               | 行 1418、23509、49529  |
| 宣判：直接定性               | 5（9%）   | 第一句就骂或诊断                                 | 行 3435、14315、32098  |
| 名号：名字打头               | 3（6%）   | 念出名字再追问                                   | 行 587、1709、30500    |
| 指令：祈使句                 | 3（6%）   | 让读者先动手                                     | 行 1696、17487、28241  |

**长度**（去空白和星号，含标点）：最短 112，p25 144，**中位 165，p75 177**，p90 186，最长 270（含外语诗，去掉该条后最长 195）。

**句尾**：句号 20（38%）、问号 16（30%）、省略号 14（26%）、叹号 3（6%）。含问号的 32 条（60%），21 条通篇没有问号。第二人称出现在 49 条（92%）。

**口吻**：纠正想象中的反对者（行 1030、6459、7975、28602、52620），这几条分在接话、通论、宣判三类里。约 12 条（23%）提到当场的物或事，其余直接写它引出的执念，不要把事件再讲一遍。

**待办线索**：可选。20 条（38%）带一个动作，多半针对自己，小而荒唐，如「试着故意激怒它」（行 17698）；个别指向别人，如「跟别人聊聊，也许能有所帮助」（行 4504）。

## 解答的写法

| 开口类型                   | 占比      | 动作                                           | 例                     |
| -------------------------- | --------- | ---------------------------------------------- | ---------------------- |
| 断言：展开一个判断         | 15（28%） | 先摆前提，平静地往下推，越说越糟或越怪         | 行 4126、5549、11441   |
| 直判：一句判决             | 10（19%） | 第一句就答问题本身：是否、事实或诊断，理由在后 | 行 11359、22980、39992 |
| 公文：汇报、公告、贺词     | 8（15%）  | 用机构的声音对你说话                           | 行 592、4508、12345    |
| 完成词                     | 6（11%）  | 短促交差，交出可疑成果                         | 行 3441、28246、45067  |
| 爆发：喝令、堆词、动作中途 | 6（11%）  | 没有过渡，声音换了                             | 行 26891、19658、17703 |
| 场景：时间、拟声或画面     | 5（9%）   | 不回答，改放一段                               | 行 23959、30573、30721 |
| 续接：接问题的省略号       | 3（6%）   | 问答是同一句                                   | 行 1701、30735、40823  |

**长度**：最短 97，p25 152，**中位 163，p75 175**，p90 206，最长 222。解答比问题长的 26 条（49%），两段大致等重。句尾句号 40（75%）、叹号 7、问号 5；末句不超过 8 字的 11 条（21%），短促收尾不是默认。

**转折方式**：转折和开口各抽各的，文体跟着开口换。

| 转折 | 占比      | 走法                                                           | 例（行）     |
| ---- | --------- | -------------------------------------------------------------- | ------------ |
| 放大 | 17（32%） | 小念头成真，按它自己的逻辑多走三步，规模失控                   | 7975、17487  |
| 直答 | 12（23%） | 答了，答案本身难堪：给事实、日期、诊断，或大问题得到平淡的现实 | 12340、9118  |
| 落空 | 7（13%）  | 要的没得到，交付旁边的东西；荒诞进度也属此类                   | 587、6370    |
| 揭伤 | 7（13%）  | 说出问题绕开的失去，改写当时的画面，少用评语                   | 30568、22975 |
| 知识 | 5（9%）   | 说明一段，末尾把人推回现场                                     | 5544         |
| 跑题 | 5（9%）   | 被别的欲望带走或叫停，忘了问题                                 | 17132、52620 |

报喜口吻包难堪 4 例（行 9122、12345、15187、39992），如「这一领悟对个人成长至关重要」（行 39992）。

**是否回答**：40 条（75%）正面回应问题或念头，13 条（25%）转开。刺多半在答案里。

**是否安慰**：反讽打气 24（45%）；冷或中性 20（38%）；不带反讽地留一点希望或好处 6（11%），如「你还有那么点希望」（行 32102）；柔和但不宽慰的回忆 3（6%）。安慰存在，但少，且排在代价之后。

## 写一条的步骤

先运行 `scripts/draw.py`，它按上面各表的占比抽出名字形状、问题开口、转折、解答开口和安慰度。没法运行时自己掷：每张表心里取一个 1–100 的数，从第一行起累加占比，落在哪行就用哪种。写多条时每条各抽一次，和上一条撞型就重抽。

1. **定事件**。写出谁在何处做了什么，带一个可数细节和一个没处理的后果。完成条件：一句话写得出，并且有人因此付了代价。
2. **定执念**。写出人物对这件事撒的小谎。完成条件：能说出他不肯承认的那一句。
3. **起名**。从事件里挑一个能指出来的东西，按抽到的形状造名，查“烂名字”。名字读起来像一本你永远不会翻开的书。完成条件：名字里有一件看得见的东西，读完猜不到解答。
4. **写问题**。按抽到的开口类型写，140—180 字，句尾按上面的比例走，句号最多；需要时带一个小而荒唐的待办。完成条件：字数合格，没有复述事件全程。
5. **写解答**。按抽到的转折、开口和安慰度写，150—180 字。完成条件：回应了问题（或有意转开），不总结道理，不写作者的安慰。末句停在一个画面、一个事实或半句话上；待办只属于问题，解答不派活（不写「请」「记得」「你该」）。

## 跑偏写法

- **鸡汤标题**。名称里没有成长或治愈类词；带“自我”的严格的自我批判是在骂人。
- **温和顿悟**。解答里“成长”“领悟”只见于行 38046、39992，后者是反讽。以“终于明白”收束的 0 条。
- **一句话包袱**。最短解答 97 字，中位 163 字。
- **五选一**。解答开口最多 28%，转折最多 32%，且两者独立。不按抽到的写，挑顺手的，写到第三条就露了。
- **问题一律反驳起手**。先让一步再顶回去，篇篇如此。接话只占 21%，多是顺着那段没写出来的对话往下说，见「问题的写法」的口吻。
- **解答一律一句短判决起手**。尤其是第一句把问题里拟人化的物件判回一件死物，再慢慢讲理由。直判只占 19%，判的是问题本身。
- **默认补效果行**。语料里没有属于思维的效果行，属性行只挂在衣物卡上；变化写在解答文字里，下一步写成任务行（见 [界面行](game-ui.md)）。
- **复述触发事件**。解锁行落在对话中，正文和它之间隔着对话；问题只有约 23% 提到当场的事。
- **机巧过度**。每句都为结尾铺垫、包袱工整，公文、账目和精确数字太干净，段长偏短。语料里很多条是诚恳的，长句一路逗号往下走，有抒情也有说明，结尾常是平常的一句。公文开口只占 15%，别当默认。
- **解答变成建议框**。末句落在退改规则、工单、复诊这类待办上，思维阁就成了提醒事项。语料的解答停在念头的去向上，不替人安排下一步。
- **把思维写成案情提示**。职业母题 8 条没有案情线索；解答指向具体人物的约 5 条（9%）。
