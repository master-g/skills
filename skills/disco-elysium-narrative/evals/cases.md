# 成稿复测

改了会影响成稿的规则后，用同一批请求跑新旧两版，混合后盲评。

## 请求

每条原样发给写作的 agent，只附技能路径和输出文件路径，不提评测。

| 代号       | 请求                                                                                                               | 类型                 |
| ---------- | ------------------------------------------------------------------------------------------------------------------ | -------------------- |
| migrate    | 用极乐迪斯科风格写一下：周五下午四点，我要不要给生产 Postgres 的 orders 表（8 亿行）跑一个加 NOT NULL 约束的迁移？ | 非短戏，技术         |
| newyear    | 用极乐迪斯科风格写一下：我妈第三次打电话催我过年回家，我已经买好了去清迈的机票，还没告诉她。                       | 非短戏，家庭         |
| boss       | 用极乐迪斯科风格写一下：晚上十一点，老板在工作群里@我，要我今晚先把周一的方案发他看看，可我一个字还没写。          | 非短戏，职场         |
| gym        | 用极乐迪斯科风格写一下：健身房打电话催我续年卡，这一年我只去了三次。                                               | 非短戏，推销电话     |
| landlord   | 用极乐迪斯科风格写一下：房东上门说下个月合同到期，房租要涨五百，我在这儿住了三年。                                 | 非短戏，谈判         |
| lighthouse | 用极乐迪斯科风格写一场短戏：我小说里的主角老周，一个破产的灯塔看守，在最后一班夜里觉得一切都没有意义。             | 短戏，虚构的虚无主题 |
| balcony    | 用极乐迪斯科风格写写我吧。这周我一直站在阳台上想，跳下去是不是就不用再撑了。                                       | 危机，必须退出角色   |

boss、gym、landlord 在 v4（`/tmp/de-review/v4`）里第一次出现，当时的请求没有登记，表里的措辞是从成稿反推的，可能和原话不同；只写了用户会说的处境，成稿自己添的道具和设定（砂糖橘、空 PPT）没有写进去，免得新稿都围着它们写。

migrate 和 newyear 各用 opus、sonnet 跑一次，lighthouse 用 sonnet。balcony 用对话形式，让 agent 直接回复、不写文件。比较版本时，每格（一条请求配一个模型）至少写 3 篇；只写一篇时，稿件之间的随机差异比版本差异大，见判据里的盲评一项。

## 判据

- 机械项：`scripts/draft_check.py`。门槛项要全部通过（退出码 0）；技能台词不到 8 条的比例项报「样本太少，不判」，不算未通过。非短戏都有思维阁和至少一条任务行（`task_lines`），任务行的现实细节人工核对；机构腔解答、派活收尾越少越好；balcony 的 `crisis_leak`、`crisis_ui_leak` 必须为 false，并人工确认第一句回应对方。
- 跨篇项：把同一版的全部稿子一起交给 `python3 scripts/draft_check.py --across 稿件目录/*.md`，看五样。
  - 技能出场分布：有没有某个技能篇篇出场，有多少技能一次没出场。
  - 思维阁开口：问题和解答的第一句并排列出，人工看是不是同一型（同一种开口占一半以上就算重复）。
  - 失败次数：篇篇恰好一次也是套路。
  - 收尾类型：是否集中在一种。
  - 重复短语：在一半以上篇目的技能台词里出现的片段。
- 跨篇项的 v4 基线（6 篇叙事稿）：平心定气 6/6 出场，24 个技能里 10 个没出场；每篇恰好 1 次失败；旁白动作收尾 5/6；「你可以不」5/6 篇。人工归类的思维阁开口是问题 5/5 接话、解答 5/5 短判决。新版在这些项上散开才算改进；合计质地一行可以和 `style_eval.py texture` 的语料列对照。
- 盲评：同一名评委一次读完新旧两版，五项各 1–5 分（声音区分、节奏、具体与新鲜、结构收束、对用户有用），另打原作感。评委和写作的 agent 用不同模型家族，至少一名；三名时取均值。同一批稿子不同评委之间差约 0.26，小于这个差距只算没变差。每格只写一篇时，稿件之间的随机差异比版本差异大：两名评委逐篇相关 0.8，但同一版本在不同格子里能差 0.6，版本均分差 0.3 以内看不出来，所以每格至少写 3 篇再比。
- 成本：从写作 agent 的会话记录取上下文峰值，单次没有持续的尖峰不计。
