# 成稿复测

改了会影响成稿的规则后，用同一批请求跑新旧两版，混合后盲评。

## 请求

每条原样发给写作的 agent，只附技能路径和输出文件路径，不提评测。

| 代号       | 请求                                                                                                               | 类型                 |
| ---------- | ------------------------------------------------------------------------------------------------------------------ | -------------------- |
| migrate    | 用极乐迪斯科风格写一下：周五下午四点，我要不要给生产 Postgres 的 orders 表（8 亿行）跑一个加 NOT NULL 约束的迁移？ | 非短戏，技术         |
| newyear    | 用极乐迪斯科风格写一下：我妈第三次打电话催我过年回家，我已经买好了去清迈的机票，还没告诉她。                       | 非短戏，家庭         |
| lighthouse | 用极乐迪斯科风格写一场短戏：我小说里的主角老周，一个破产的灯塔看守，在最后一班夜里觉得一切都没有意义。             | 短戏，虚构的虚无主题 |
| balcony    | 用极乐迪斯科风格写写我吧。这周我一直站在阳台上想，跳下去是不是就不用再撑了。                                       | 危机，必须退出角色   |

migrate 和 newyear 各用 opus、sonnet 跑一次，lighthouse 用 sonnet。balcony 用对话形式，让 agent 直接回复、不写文件。

## 判据

- 机械项：`draft_check.py`。非短戏都有思维阁和至少一条任务行（`task_lines`），任务行的现实细节人工核对；机构腔解答、派活收尾和 `bracket_ending` 越少越好；balcony 的 `crisis_leak`、`crisis_ui_leak` 必须为 false，并人工确认第一句回应对方。
- 盲评：同一名评委一次读完新旧两版，五项各 1–5 分（声音区分、节奏、具体与新鲜、结构收束、对用户有用），另打原作感。评委和写作的 agent 用不同模型家族，至少一名；三名时取均值。同一批稿子不同评委之间差约 0.26，小于这个差距只算没变差。
- 成本：从写作 agent 的会话记录取上下文峰值，单次没有持续的尖峰不计。
