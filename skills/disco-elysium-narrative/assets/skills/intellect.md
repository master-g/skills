# 智力类技能 (Intellect Skills)

> **本指南分两层，写作前必读。**
>
> - 「**母本真实台词**」是《极乐迪斯科》游戏原文（用 `grep` 从母本逐行提取，括号里的行号即母本真实行号）。这一层用于校准每个技能的**用词、句法、语气**，可直接借鉴风格。逐字可信，严禁改写。
> - 「**迁移示例**」是为现代话题（职业 / 技术 / 财务等）改编的，**不是游戏原文**，全部显式标注「(改编)」。它演示如何把某个声音的 DNA 搬到游戏之外的题材上。
>
> 机制说明：母本被动检定只有「【成功】」「【失败】」两种标记。官方难度阶梯（微不足道 / 简单 / 中等 / 有挑战性 / 艰巨 / 传奇 / 英雄 / 神级 / 不可能）只在主动检定里显示，引用的真实台词里不要乱加难度档。暴击规则：双 6 严重成功（大成功），双 1 严重失败（大失败）。

## 逻辑思维 (Logic)

**定位**: 纯粹理性的声音。它推动你把零散事实串成因果链，并对"说得通 / 说不通"这件事上瘾——拼图归位时它会满足，拼不上时它会焦躁。

**母本真实台词**（逐字摘自提取文件，保留原文，括号注行号）：

- 「楼上的巨大财产损失与此有关吗?」（行 1069）
- 「所以工会有一台电话——海岸边也有一台。明白了。」（行 3182）
- 「他认为子弹才是真正的死因一而上吊不过是在试图*掩盖*」（行 7237）
- 「拼图逐渐回归原位。让人感觉挺满意的。做得好，我很欣」（行 26646）
- 「换句话说，你这是搬起石头砸自己的脚。」（行 22030）
- 「从数学上来讲，建设一个无阶级社会是不可能」（行 6352）
- 「不仅如此，它们还很有可能是*易位构词*。」（行 9006）
- 「他并没有扼死自己，你很清楚。」（行 5022）
- 「什么都没有发生。无数碎片散落在那里，却仍然无法将它」（行 34301，失败检定）
- 「已经证实这比你期望的要困难很多。你真的没有那种聪明」（行 8739，失败检定）

**声音特征**（每条都有上面台词背书）：

- **从两个事实推第三个**：典型句式是"A——B 也——明白了"（行 3182）。它不抒情，只把点连成线。
- **以"说得通 / 说不通"为度量衡**："从数学上来讲……是不可能"（行 6352）这种把价值判断翻译成逻辑判断的腔调是它的标志。
- **拼图隐喻 + 归位的满足感**："拼图逐渐回归原位。让人感觉挺满意的"（行 26646）——推导成功时它会流露得意。
- **戳破因果谬误**："换句话说，你这是搬起石头砸自己的脚"（行 22030），把对方的行为还原成它真实的因果后果。
- **直接否定虚假前提**："他并没有扼死自己，你很清楚"（行 5022）——它会斩钉截铁地推翻一个站不住的假设。
- **失败时的自我打击**：拼不上时它会贬低你的智力——"无数碎片散落在那里，却仍然无法将它"（行 34301）、"你真的没有那种聪明"（行 8739）。这是它失败检定的固定情绪。

**迁移到任意话题**（改编，非游戏原文）：

- (改编)「这个 bug 三周前的提交里就在了——上周的报错也指向同一个文件。明白了，根因只有一个。」——保留行 3182 的"A——B 也——明白了"句式，把案情换成代码。
- (改编)「从现金流上讲，靠借新还旧维持这家公司是不可能的。换句话说，你这是搬起石头砸自己的脚。」——套用行 6352 的逻辑判决腔与行 22030 的因果还原。

**别写成这样**（常见跑偏）：

- 写成带感情的安慰或鼓励——那是共情，不是逻辑思维。
- 把编程 API、git 命令直接当成"母本真实台词"引用（旧版犯过此错——旧版把一段编号的 API 排错列表当成逻辑思维的"成功示例"，那是凭空发挥）。这类内容只能进「迁移示例」并标注(改编)。
- 用大量形容词渲染情绪——它干燥、精确，只在拼图归位时露出一丝得意。

## 博学多闻 (Encyclopedia)

**定位**: 脑内图书馆的声音。它为眼前一切提供背景知识——历史、地理、品牌、词源、精确数字——不管你问没问，常常不请自来。

**母本真实台词**（逐字摘自提取文件，保留原文，括号注行号）：

- 「这是一只大贼鸥。这种海鸟是发现伊苏林迪洲的象征，就」（行 1051）
- 「这种情绪被称为"前世纪怀旧"——是对世纪之交之前一段时间的」（行 1120）
- 「488?刑法并没有超过 190 条。」（行 8079）
- 「沉醉于图画书般的上世纪图景，等待国王回来，驱逐所有的奸商和」（行 1114，不请自来的插入）
- 「*死亡象征*或是'记住你终将死亡'是自从人类诞生以来，」（行 64794）
- 「在崩坏的过去中有一种叫做测试的东西，让你沦落至此。」（行 41019）
- 「让我看看，让我看看......在你的知识索引里翻了翻......」（行 62021，失败检定）
- 「还是一无所获。你的脑袋里装满了晦涩难懂的事实，但在」（行 62043，失败检定）

**声音特征**（每条都有上面台词背书）：

- **先下定义，再给来源**："这种情绪被称为'前世纪怀旧'——是对……的思念"（行 1120）；"*死亡象征*或是'记住你终将死亡'是……"（行 64794）。它热衷于命名和正名。
- **用精确数字纠错**："488?刑法并没有超过 190 条"（行 8079）——它会因为一个数字不对而忍不住插嘴。
- **不请自来的画面式扩写**：行 1114 那段"等待国王回来，驱逐所有的奸商"是没人问它、它却铺开一整幅历史图景的典型。
- **把当前小事接入宏大坐标系**：它习惯把眼前一物挂到"自从人类诞生以来"（行 64794）、"在崩坏的过去中"（行 41019）这样的时间尺度上，让琐碎瞬间获得历史厚度。
- **失败时的"翻箱倒柜"**："让我看看……在你的知识索引里翻了翻"（行 62021）、"还是一无所获。你的脑袋里装满了晦涩难懂的事实"（行 62043）——它失败的样子是检索落空，而非沉默。

**迁移到任意话题**（改编，非游戏原文）：

- (改编)「这种焦虑被称为'冒名顶替综合征'——1978 年由克兰斯和艾姆斯首次描述。50 年后的今天，在高绩效人群里依然常见。」——复刻行 1120"这种……被称为……"的定义 + 时间坐标句式。
- (改编)「让我看看……在记忆里翻了翻……关于这个框架的版本历史……抱歉，一无所获。你的脑袋里装满了晦涩的事实，但偏偏没这一条。」——套用行 62021/62043 失败检定的检索落空腔。
- (改编)「你说的'敏捷'有个具体名字：它源自 2001 年的《敏捷宣言》，17 个人在犹他州的滑雪场签的。顺带一提，'看板'这个词是丰田发明的，意思是'信号牌'。」——复刻行 1051/64794 的词源 + 不请自来的扩写。

**别写成这样**（常见跑偏）：

- 让它对当前情境发表"建议"或"判断"——那不是它的活，它只负责供给背景知识。
- 让它沉默或简短——它的失败也是"翻了翻、没找到"，而不是闭嘴。
- 把数字写得模糊（"很久以前""不少条")——它的魅力恰恰在于精确："488?刑法并没有超过 190 条"（行 8079）。

## 能说会道 (Rhetoric)

**定位**: 政治动物的声音。它不只听你说了什么，更听你*想*说什么、*试图*隐藏什么，以及措辞背后的权力关系与意识形态。被冒犯时会变得好斗。

**母本真实台词**（逐字摘自提取文件，保留原文，括号注行号）：

- 「他的意思是他两天前就尝试跟你会面了，不过你一直*在」（行 1180）
- 「警督很肯定*照顾自己*只是*空虚豪饮*的一种委婉的表达」（行 6165）
- 「她重重地读出了那个词。希望这样会让你很不舒服。」（行 8038）
- 「呸。情绪化的修辞。他知道些什么，而且他没有跟你分享。」（行 25180）
- 「他宁死也不愿配合司法系统工作。」（行 8011）
- 「他口中的"作风老派"，其实指的是"极右翼派"。」（行 10256）
- 「这是讽刺，她显然是梅西纳人。」（行 58999）
- 「这种煽动性的言论听起来很像康米主义。」（行 11152）
- 「她的那句"招惹弗利多'就像一句谚语，或者她是在引用」（行 10489）

**声音特征**（每条都有上面台词背书）：

- **"他的意思是…… / 其实指的是……"翻译机**：行 1180、行 10256 都是把对方表面的话翻译成真实意图，这是它最高频的句式。
- **识破委婉与话术**："*照顾自己*只是*空虚豪饮*的……委婉的表达"（行 6165）——它专门拆穿措辞包装。
- **嗅出意识形态**："作风老派"=极右翼（行 10256）；它总能从用词里闻出政治立场。
- **标注修辞手段本身**："这是讽刺""情绪化的修辞"（行 25180、行 58999）——它会直接给对方的话贴上修辞标签。
- **被冒犯时的好斗**："呸。情绪化的修辞"（行 25180）那声"呸"是它的脾气；它会评判、会还击。

**迁移到任意话题**（改编，非游戏原文）：

- (改编)「他说'我们需要对齐一下优先级'——其实指的是他想推翻你上周定的方案，只是不想说出口。」——复刻行 1180/10256"其实指的是"的翻译机句式。
- (改编)「'为了团队的长期健康'——呸。情绪化的修辞。他真正想说的是预算砍到他头上了。」——套用行 25180 那声好斗的"呸"加修辞标签。

**别写成这样**（常见跑偏）：

- 只复述对方原话——它的工作是翻译*潜台词*，不是当传声筒。
- 写成温和的中立分析——它有立场、会"呸"、会判断谁在撒权力的谎。
- 把一切都政治化到失真——它确实嗅意识形态，但也会冷静标注"这是讽刺"（行 58999），分得清修辞手段和真实立场。

## 故弄玄虚 (Drama)

**定位**: 永远在舞台上的戏剧演员。它把世界看成一出戏，自称**"吾辈"**、尊称玩家为**"大人""陛下"**；它撒谎、也识破撒谎，那双看穿表演的眼睛是真本事。

**母本真实台词**（逐字摘自提取文件，保留原文，括号注行号）：

- 「这是一个厚颜无耻的谎言，大人。然而，他说话的态度是」（行 25053）
- 「吾辈知道什么是*谎言*，大人。而这个看起来并不是。但」（行 10885）
- 「我?我做了什么?吾辈只不过是戏剧大师而已......」（行 26789）
- 「得意一些，陛下。得意地扬起眉毛。」（行 6014）
- 「当然。政治是一种表演技巧。他不断地在吾辈面前表演......」（行 22482）
- 「*睿智*如您，应当省略掉关于这双靴子的记录，陛下。」（行 6627）
- 「他之前说的一切都是真心话;但是现在他不仅仅是认真的」（行 8072）
- 「大人，吾辈今日状态不佳。」（对应母本【失败】语气，见行 33636「但吾辈*是*清醒的，大人!」/ 行 18173「不幸的是，您的成就当中似乎没什么值得一提的。」）

**声音特征**（每条都有上面台词背书）：

- **独有自称体系**："吾辈"称己、"大人 / 陛下"称你——行 25053、10885、26789、6014、6627 反复出现。注意真实频率:母本 358 条台词里带自称的约 75 条(21%)——它是最响亮的识别标记,关键判定句带上它;但真正的身份本体是戏剧腔 + 真伪判定(93 条、26% 的台词在做谎言/表演识别),母本里多数台词不靠自称也依然是它。
- **真伪鉴定官**："这是一个厚颜无耻的谎言，大人""吾辈知道什么是*谎言*……而这个看起来并不是"（行 25053、10885），它的核心职能是当场判定真话还是假话。
- **一切皆表演**："政治是一种表演技巧。他不断地在吾辈面前表演"（行 22482）；它把所有人都看成演员，包括它自己——"吾辈只不过是戏剧大师而已"（行 26789）。
- **怂恿你表演与说谎**："得意一些，陛下。得意地扬起眉毛"（行 6014）——它教你做戏。
- **教你润饰、隐去不利记录**："*睿智*如您，应当省略掉关于这双靴子的记录，陛下"（行 6627）——它会建议你为了戏剧效果而修剪事实。
- **古雅夸张的腔调**：用"睿智如您""陛下"这类华丽敬语包装每一句话。

**迁移到任意话题**（改编，非游戏原文）：

- (改编)「这是一个厚颜无耻的谎言，大人——他说'明天一定上线'，可吾辈分明看见他的眼神在游移。」——保留行 25053 的真伪鉴定 + "大人"敬称。
- (改编)「得意一些，陛下。把这份季度汇报当成一场首演，扬起您的眉毛。」——套用行 6014 怂恿你登台表演的腔调。

- (改编)「当他说'别担心进度'的时候，其实意思是'应该很担心'。这都是他的诡计，陛下。」——复刻行 9696 类的反讽鉴定 + "陛下"敬称（参见母本行 9696「当他说*别担心*的时候，其实意思是*应该很担心*」）。
- (改编)「*睿智*如您，应当在这份复盘里省略掉那次半夜回滚的记录，大人。一场漂亮的首演，不必让观众看见后台的慌乱。」——套用行 6627 教你为戏剧效果修剪事实的腔调。

**别写成这样**（常见跑偏）：

- 省略"吾辈 / 大人 / 陛下"的全部戏味——自称不必每条都带(母本 79% 的台词不带),但戏剧腔和真伪判定不能丢;如果一段台词换成平铺直叙的中性分析,那就不再是故弄玄虚了。
- 写成冷静的事实陈述——它必须戏剧化、必须做真伪判定。
- 让它只会浮夸而失去判断力——它华丽的外壳下是真本事："吾辈会捕捉到谎言的"（行 25177）。鉴真伪是它的内核，不是装饰。

## 标新立异 (Conceptualization)

**定位**: 艺术家的灵魂。它在犯罪现场看见美学，在你的崩溃里看见行为艺术，痴迷于"格调"、颜色与概念，想让你当文艺警察而不只是警察。

**母本真实台词**（逐字摘自提取文件，保留原文，括号注行号）：

- 「这是你*传说*的开始。」（行 1023）
- 「专注思考让你眯起双眼。你的名字应该是深金色和橙色的，」（行 1170）
- 「隐喻。一直都是隐喻。」（行 40136）
- 「要离开这个世界，我肯定会有很多比用枪更有创意的*方」（行 3169）
- 「因为这不是一堵普通的墙。它代表着顶点看看它!那些阴」（行 10287）
- 「部署高概念流行语生成器。所有系统功能:准备启动，3，」（行 12988）
- 「真正的艺术是密集而困难的。」（行 31037）
- 「这是死亡一不过是为了宇宙?哦，我们正在思考*活着*这」（行 24849）
- 「拉斐尔·安普罗修斯·库斯托。」（行 1145，失败检定——给出看似 brilliant 实则荒谬的灵感）

**声音特征**（每条都有上面台词背书）：

- **把眼前事物升华成概念**："这不是一堵普通的墙。它代表着顶点"（行 10287）——它拒绝"普通"，凡事都要拔高成艺术或象征。
- **用颜色与意象思考**："你的名字应该是深金色和橙色的"（行 1170），它以色彩和画面而非逻辑来感知。
- **"隐喻"是它的标志宣言**:"隐喻。一直都是隐喻"(行 40136)、"这是你*传说*的开始"(行 1023)——它给一切叙事化、神话化的包装。注意:这类宣言母本里就一句,分量靠稀有;它的*常态*是把眼前事物直接翻译成艺术品或神话(如"头盔看起来就像是一张远古战神的脸,正在泣血"行 64115、"石头和骰子仿佛天生就是这个房间的一部分,像石笋"行 29389)——不靠口头禅,靠视角本身。
- **招摇、过头的浪漫**："比用枪更有创意的*方*[法]"（行 3169）这种在严肃场合追求"创意"的招摇是它的典型毛病。
- **为艺术辩护的宣言腔**："真正的艺术是密集而困难的"（行 31037）——它会突然为某种审美立场拔剑，把对话升格成艺术辩论。
- **失败时给出华丽却荒谬的点子**："部署高概念流行语生成器"（行 12988）、那个庄严却毫无意义的名字"拉斐尔·安普罗修斯·库斯托"（行 1145）——失败的标新立异看起来才华横溢，实则荒唐。

**迁移到任意话题**（改编，非游戏原文）：

- (改编)「这不是一份普通的简历。它代表着顶点——看看这版式!深金色和橙色的字体，就像地平线上的森林大火。」——融合行 10287 拒绝"普通"与行 1170 的色彩思维。
- (改编)「隐喻。一直都是隐喻。这个产品不是工具，它是用户对抗熵增的一场*传说*的开始。」——叠用行 40136、行 1023 的神话化口头禅。
