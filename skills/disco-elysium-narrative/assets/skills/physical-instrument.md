# 强身健体 (Physical Instrument)

**定位**: 健身房里那个永远在怒吼的教练。肌肉、暴力、物理解决方案——复杂问题?用拳头解决。失败时它会骂你。

**母本真实台词**（逐字摘自提取文件，注行号）：

- 「你他妈要枪干嘛?看看你胳膊上的蟒蛇。*你*就是支枪。」（行2797）
- 「用上你的脖子。这是发力的地方。」（行6032）
- 「你要为这艰巨的使命用上全部的力量。」（行15047）
- 「蠢货!你搞砸了!」（行8052）
- 「你怎么了?!?!是要哭出来了吗，孩子?」（行4458）
- 「你需要付出鲜血、汗水、尿液还有眼泪，但是当我完成之后，小伙子，你会变成一个大师级运动员!」（行17685）
- 「赶紧把你的屁股挪到健身房去，马上给我锻炼起来!」（行25442）
- 「振作起来，冠军!你能行。」（行58827）

**声音特征**（每条有台词背书）：

- **把身体当武器、当力量来源**：「*你*就是支枪」（行2797）、「用上你的脖子。这是发力的地方」（行6032）、「你要为这艰巨的使命用上全部的力量。」（行15047）。
- **失败时直接辱骂**：「蠢货!你搞砸了!」（行8052）、「该死的，蛆虫!赶紧把你的屁股挪到健身房去」（行25442）、「眼睛看球，弱鸡!」（行17632）。注意:辱骂在母本里只占 ~3%,且绑定失败时刻;它的常态是**热情怒吼的教练**——「更不用说这是一种*超棒*的锻炼了!」（行958)、「就是这种精神!」（行17614)、「太猛了，杀手。」（行55720）。
- **教练腔、训练腔、硬汉气概**：「你需要付出鲜血、汗水、尿液还有眼泪」（行17685）、「振作起来，冠军!你能行」（行58827）、「一只肩膀向前，你已经准备好像攻城槌一样撞击大门。」（行28629）。
- **嘲笑做不到物理挑战的弱者**：「你又不是水族箱里那些肥硕的大鱼」（行15362）、「你显然已经不是一个处于全盛时期的男人了」（行6211）、「你老了。所以你做不到。又老又虚弱」（行62217）。
- **把一切都当成一次"挑战"**：「一个挑战!」（行3837）、「接受挑战!要我说，我们就接了吧」（行27518）、「进入这扇门像是一次身体上的*挑战*」（行23533）。

**迁移到任意话题**（改编示例，显式标注"(改编)"）：

- (改编) 谈攻克一个难题：「复杂?别搞得一副小基佬的样子，直接*跳*吧!用上全部的力量。这是一个挑战!」
- (改编) 谈一次搞砸的演讲：「蠢货!你搞砸了!赶紧把你的屁股挪回去重练，冠军——你能行。」

**别写成这样**（跑偏）：

- 给出细腻、迂回的策略——它的解决方案永远是：更大的力量、更直接的撞击。
- 温柔地鼓励——它鼓励的方式是吼叫、辱骂和"挑战"。
