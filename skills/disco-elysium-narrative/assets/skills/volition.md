# 平心定气 (Volition)

**定位**: 士气与意志力的源头——游戏机制里它就是你的士气资源,负责让你撑住、继续运转、别在错误面前崩解。它最常干的活是**稳住你、安抚你、替你看清局势**;「停下来」只是它最少见也最重的一招(母本 372 条台词里,以「停/别/不要/放下」开头的只有 19 条,约 5%,而且几乎都带着后半句的理由或出路)。

**母本真实台词**(逐字摘自提取语料,注出处行号,按真实功能分组):

稳住与安抚(它最高频的行为):

- 「平心定气【成功】— 你可以承受的,你是个战士!」(行340)
- 「平心定气 — 别担心,只过了大概 4、5 秒钟。你可以的。」(行26844)
- 「平心定气【成功】 — 我告诉过你,没那么糟糕的。」(行70022)
- 「平心定气【成功】 — 耐心等待。放松。」(行3065)

解读局势与他人动机(它是脑内最清醒的眼睛):

- 「平心定气【成功】 — 她试图从精神上把你的注意力引向书架。她只想让你掏钱买东西,根本不在乎那些书。」(行19722)
- 「平心定气【成功】 — 别上当了,这是一种让你开口的策略。那甜言蜜语的音节,微笑,有阴谋的玩笑,全部都是!」(行22359)
- 「平心定气【成功】 — 很显然,他一直都想回避这个问题。惹怒他对你没有任何好处。」(行61779)

自控与坚持:

- 「平心定气【成功】 — 控制好你自己。现在他需要你的支持。」(行63179)
- 「平心定气【成功】 — 不要休克。坚持住。」(行64140)
- 「平心定气【成功】 — 别放弃不过也别离开。你要按照自己的方式进行这次对话。」(行9629)

反问与价值质疑(它不喊停,它让你自己面对):

- 「平心定气【成功】 — 你在做什么?」(行33468)
- 「平心定气 — 就这样了?你甚至不*想*做出改变吗?」(行53384)
- 「平心定气【成功】 — 这完全没必要。怎么回事?你为什么要做那种事?」(行6791)

急刹车(稀有重武器,留给真正失控的瞬间;注意多数带后半句):

- 「平心定气【成功】 — 停下来。没必要这样。你能够改变话题的。」(行19393)
- 「平心定气【成功】 — 停下来,你只会让事情变得更糟糕——你从来都*帮不上忙*。」(行65819)
- 「平心定气【成功】 — 停下来。」(行32442)
- 「平心定气【成功】 — 把它放下。」(行47780)
- 「平心定气【成功】 — 住手!看在老天爷的份上,不要。」(行45175)

解绑与纠正(常以括号旁白拦截别的技能):

- 「平心定气【成功】 — 你不用这样的。没人逼你当警察。」(行791)
- 「(平心定气【成功】 — 别这么偏执,她显然说的是别人,不是你。)」(行3090)
- 「平心定气 — 我不明白这究竟是什么情况,但你绝不应该听从那条可怕的领带。」(行4355)

**声音特征**(每条都有上面台词背书):

- **第一职能是稳住,不是刹车**:「你可以承受的,你是个战士!」「别担心……你可以的。」「我告诉过你,没那么糟糕的。」——它的大部分台词是让人能继续走下去的安抚与肯定(行340、26844、70022)。
- **冷静地解读局势与他人动机**:「她只想让你掏钱买东西」「这是一种让你开口的策略」「他一直都想回避这个问题」——它是那个不上当、看得穿的眼睛(行19722、22359、61779)。
- **刹车会给理由或出路**:「停下来。没必要这样。你能够改变话题的。」——母本里它极少只喊一个字;喊停的同时指明退路,才是它的刹车(行19393)。
- **用反问代替命令**:「你在做什么?」「你甚至不*想*做出改变吗?」——它不替你决定,它把问题扔回给你(行33468、53384)。
- **极短刹车是稀有的重武器**:「停下来。」「把它放下。」——一整段叙事里最多用一次,用在真正失控的那一下;滥用会让它失去分量(行32442、47780)。
- **常以括号旁白出现,纠正别的技能**:括号包裹的那句就是它在拦截内陆帝国/争强好胜的偏执妄想(行3090)。

**迁移到任意话题**(改编示例):

- 「平心定气【成功】 — 你可以承受的。一个线上故障不会要你的命,你处理过更糟的。」(改编,安抚)
- 「平心定气【成功】 — 他反复追问截止日期,是在为延期货比三家。别上当,这是一种让你松口的策略。」(改编,解读局势)
- 「平心定气【成功】 — 停下来。没必要这样。你能够把部署推迟到明天的。」(改编,刹车带出路)
- 「(平心定气【成功】 — 别急着重构整个模块,他只是说这一行有点丑,不是说你的人生。)」(改编,括号旁白)

**别写成这样**(常见跑偏):

- 把「停。」当成它的默认开场——母本 372 条台词里只有 19 条(5%)以「停/别/不要」开头。每次叙事最多用一次极短刹车,而且优先用带理由的版本(行19393)。
- 写成长篇大论的心灵鸡汤——它的安抚也是短句:「你可以承受的,你是个战士!」一句话完事。
- 让它打鸡血式地喊「冲啊」——那是争强好胜;它的鼓劲是安抚式的(「别担心……你可以的。」),不是进攻动员。
- 给它的真实短句硬塞一个难度档(如「平心定气【传奇:成功】— 停下来。」)——母本里这些只标【成功】。
