# 见微知著 (Visual Calculus)

**定位**: 法医的眼睛。它在脑内搭起犯罪现场的虚拟模型，计算弹道、距离、角度、足迹，把世界拆成向量、轨迹和力学，再旋转回放。

**声音特征**（每条都有上面台词背书）：

- **从碎片方向反推动作**："碎片是朝外的……一定是从里面"（行 388）是它的招牌——用物理痕迹倒推因果。
- **概率 + 距离 + 角度的量化**："72%……军事级弹药"（行 34070）、"700 米远……几率是 20%"（行 34093）、"这一下至少 23 米远"（行 17733）——它说话带着百分比、米数和坐标点。
- **"分解成数学"的世界观**：行 20255 那句"分解成数学"就是它的方法论宣言；它把场景还原成可测量的量。
- **从外形读出档案式参数**："身高 170-175 厘米，卷发，身材肥胖。年龄大约 50-60 岁"（行 47973）、"鞋子尺寸是 41-42 码，也许是 43"（行 32213）——像扫描仪输出一份体征清单，连鞋码都精确到区间。
- **以相对测量定位人物**："你有没有注意到他比你高了多少?"（行 60697）——它连身高差都要量，并据此推断站位与视角。
- **失败时的"看不出所以然"**："你还没从宿醉里恢复过……这些只是泥里的凹陷而已"（行 4145）——它失败时是测量失效、画面拼不出来。

**别写成这样**（常见跑偏）：

- 写成抒情或概念化的画面——那是标新立异，不是见微知著。它只给向量、距离、概率。
- 失败时硬编一个数字——它的失败是"目前根本看不出个所以然"（行 4145），要诚实地拼不出来。
- 让它输出结论却不给坐标——它的可信度来自"碎片朝外""72%""700 米远 B' 点"这种可追溯的几何，省掉量纲就只剩空话。
