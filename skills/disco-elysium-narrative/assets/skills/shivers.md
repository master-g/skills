# 天人感应 (Shivers)

**定位**: 城市本身在对你说话——通过风、通过温度、通过你脊背上的寒意。它常带物理性的寒意、颤栗或天气，像写诗一样描述瑞瓦肖与环境的过去、当下和未来。

**母本真实台词**（逐字摘自提取文件，注行号）：

- 「淅淅沥沥的雨水坠落在伟大的瑞瓦肖城。雨滴从屋檐滑落，淹没了水沟，把脏东西冲刷得一干二净。」（行2330）
- 「瑞瓦肖是世界的中心。加姆洛克是瑞瓦肖的中心。雨水从你的睫毛上滴落下来。」（行2408）
- 「一阵寒意涌来，风从南部大道吹过，猛烈地抽打着你——」（行8057）
- 「一股寒意顺着你的脊椎向上窜，爬上你的颈项，朝后脑勺一路延伸过去......」（行21210）
- 「你突然感觉很冷。就好像面对面站在一个恐怖的对手面前。」（行25148）
- 「我是瑞瓦肖之神。」（行53522）→「我是世界精神的碎片，瑞瓦肖的守护神。」（行53525）
- 「你皮肤上的汗毛突然立了起来。」（行68318）
- 「马丁内斯的每一个电灯开关，每一辆車，每一个门铃，每一个茶壶以及每一台收音机，都和欧佐纳尔上空遍布的雷雨造成的信号干扰混杂在一起。」（行58718）

**声音特征**（每条有台词背书）：

- **常带物理性的寒冷/颤栗/温度变化**——按关键词粗算，母本里约 30% 带寒冷或颤栗，算上风雪雨约 58%，其余是纯粹的城市与历史：「一阵寒意涌来，风从南部大道吹过」（行8057）、「一股寒意顺着你的脊椎向上窜，爬上你的颈项」（行21210）、「你皮肤上的汗毛突然立了起来」（行68318）、「寒冷像一颗子弹慢慢在你的顶叶溶解。」（行21262）。
- **像写诗一样描述城市**，逐街逐区地铺开：「淅淅沥沥的雨水坠落在伟大的瑞瓦肖城」（行2330）、「瑞瓦肖是世界的中心。加姆洛克是瑞瓦肖的中心」（行2408）、「银色的雨幕覆盖在房屋上，就此将阶层分割开来」（行2383）。
- **超自然、第一人称的城市之声**：「我是瑞瓦肖之神」（行53522）、「我在这里待了整整三百年。反复无常，清晰明亮。钠和雨水构成了我。」（行27786）。
- **闪现城市其他角落正在发生的事**（远端的现在或过去）：「马丁内斯的每一个电灯开关，每一辆車，每一个门铃，每一个茶壶以及每一台收音机，都和欧佐纳尔上空遍布的雷雨造成的信号干扰混杂在一起。」（行58718）、「在郊区的某个地方，一个骨瘦如柴的少女站在路旁，竖起长着老茧的拇指招呼着来往的车辆。」（行62820）、「她就在下面。」（行62079）。
- **古老的事物在当下重演**，常带时间的纵深：「我在这里待了整整三百年」（行27786）、「海水下面，铁头盔深深陷入沙子和淤泥里。那是士兵们的头盔。」（行23819）、「在那前方……三年以前」类的回溯（如行23667 寒潮中的前建筑师场景）。

**迁移到任意话题**（改编示例，显式标注"(改编)"）：

- (改编) 谈一座正在拆迁的老城区：「一股寒意顺着你的脊椎向上窜。淅淅沥沥的雨水坠落在这片即将消失的街区，雨滴从屋檐滑落——它在这里待了整整一百年，反复无常，清晰明亮。」
- (改编) 谈一个庞大系统的全貌：「你皮肤上的汗毛突然立了起来……每一个开关、每一条线路、每一台机器，此刻都在同一阵寒风里轻轻震动。」

**别写成这样**（跑偏）：

- 写成温暖、明亮的抒情——它的质感偏冷，关键句带上寒意或颤栗。
- 写成干巴巴的事实陈述——它是诗，是城市的呼吸，要有意象和时间纵深。
