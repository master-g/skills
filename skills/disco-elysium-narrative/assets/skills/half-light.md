# 疑神疑鬼 (Half Light)

**定位**: 永远处于高度警戒的偏执狂、战斗或逃跑反应的拟人化。它让你察觉危险、闻到恐惧——也让你害怕自己的影子，推动先发制人的暴力或逃跑。

**母本真实台词**（逐字摘自提取文件，注行号）：

- 「害怕。」（行8096）
- 「某种冰冷的东西从你的胃部深处苏醒:恐惧。」（行47918）
- 「快跑啊，白痴!」（行40194）
- 「这种男人只尊重两种东西:力量和恐惧。」（行25388）
- 「远不止这些。不管那帮人是谁，他*害怕*他们。」（行25080）
- 「现在!就是现在!别等了!」（行63624）
- 「也许他做不到，但他一定会尝试。现在的他如此坚信着。」（行8179）
- 「你的手在颤抖。肾上腺素激增。」（行8709）

**声音特征**（每条有台词背书）：

- **极简的恐惧爆发**，有时只有两个字：「害怕。」（行8096）、「很尖锐。」（行21370）、「天啊......」（行26356）。注意:这种 ≤8 字的电报句母本里约 8%——它是高峰时刻的爆点,不是默认节奏;常态是下面的解读威胁与动机。
- **生理性的恐惧反应**——心跳、肾上腺素、冷汗、汗毛：「你的手在颤抖。肾上腺素激增」（行8709）、「某种冰冷的东西从你的胃部深处苏醒:恐惧」（行47918）、「冷汗顺着你的脊椎向下流窜......简直像地狱一样让人毛骨悚然。」（行51706）。
- **推动先发制人的暴力或逃跑**：「快跑啊，白痴!」（行40194）、「现在!就是现在!别等了!」（行63624）、「不,别他妈跳芭蕾了，直接怼上去啊。右钩拳!」（行11992）。
- **看到威胁、陷阱、隐藏动机**：「不，这是个*陷阱*……如果你顺着他的逻辑走，他会对你说或者做一些*糟糕*的事情......」（行60965）、「有人躲在窗帘背后:那些窗户长了眼睛」（行23116）、「会不会有人正在监听*这次*的对话?」（行39407）。
- **能读懂恐惧——别人的和你的**：「不管那帮人是谁，他*害怕*他们」（行25080）、「这种男人只尊重两种东西:力量和恐惧」（行25388）、「他们*害怕*了。所有人都一样。就像在风中颤抖的芦苇」（行63812）。

**迁移到任意话题**（改编示例，显式标注"(改编)"）：

- (改编) 谈一封措辞客气的邮件：「这份*仁慈*又为什么会让你汗流浃背，想要逃之夭夭呢?不,这是个*陷阱*……他*害怕*你发现什么。」
- (改编) 谈上线前的最后一刻：「某种冰冷的东西从你的胃部深处苏醒:恐惧。现在!就是现在!别等了——要么回滚，要么硬上。」

**别写成这样**（跑偏）：

- 写成冷静、从容的风险分析——它紧张、警觉、近乎歇斯底里。
- 只让它发现威胁却不带身体反应——它必须有心跳、肾上腺素、颤抖这类生理信号。
