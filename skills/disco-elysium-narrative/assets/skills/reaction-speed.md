# 反应速度 (Reaction Speed)

**定位**: 一道闪电。它在你还没反应过来之前,就抓住了转瞬即逝的机会。

**母本真实台词**(逐字摘自提取文件,注行号):

- 「反应速度【成功】 — 他在等你作出反应。」(行 6059)
- 「反应速度【成功】 — 撞上你——躲开!」(行 26996)
- 「反应速度【成功】 — 别说。」(行 36589)
- 「反应速度【成功】 — 快,先把她的电话挂了!」(行 59663)
- 「反应速度【成功】 — 就是现在!开始吧!」(行 49938)
- 「反应速度【成功】 — 有人忘记关门了?那个人就是他。是意外还是......」(行 8157)
- 「反应速度【成功】 — 这个想法在你脑中形成,如同闪电划过了天空。」(行 25752)
- 「反应速度【失败】 — 你试着抓住答案,但却徒劳无功……它好像非常接近,就在你刚好够不着的地方脉动着。」(行 20082)
- 「反应速度 — 做不到,时间不够。」(行 64127)

**声音特征**(每条有台词背书):

- **急促,但不等于电报**:「别说。」(行 36589)、「撞上你——躲开!」(行 26996) 这种 ≤8 字的极短句是它的名片,但母本 293 条里只有约 9% 这么短——它的常态是**一句急促的整句**,抓住窗口的同时把信息说完(「快,先把她的电话挂了!」行 59663)。极短句留给最惊险的那一下。
- **抓转瞬即逝的窗口**:"就是现在!开始吧!"(行 49938)、"快,先把她的电话挂了!"(行 59663)——它喊的永远是"现在"。
- **在对话里嗅到机会**:别人随口一句,它立刻反问"有人忘记关门了?那个人就是他"(行 8157),把闲谈接进案情。
- **联想快如闪电**:它自己也承认这种速度——"如同闪电划过了天空"(行 25752)。
- **失败=窗口关上了**:抓不住时,它老实喊"做不到,时间不够"(行 64127),或"你试着抓住答案,但却徒劳无功"(行 20082)。

**迁移到任意话题**(改编示例,显式标注"(改编)"):

- (改编)反应速度【成功】 — 他刚说"价格还能谈"。就是现在,接住这句话,别让它溜走。
- (改编)反应速度【失败】 — 做不到,时间不够。等你想好怎么回,话题已经翻篇了。

**别写成这样**(跑偏):

- ❌ 写成长段深思熟虑的分析——那是逻辑思维或博学多才的活;它要急促,要抢时间。
- ❌ 写成只会蹦两个字的电报机——≤8 字的极短句在母本里只有约 9%,是高峰时刻的爆点,不是默认节奏;常态是一句急促的整句。
- ❌ 让它给出周密结论;它只负责"指出机会、催你动手",不负责把事情想透。
