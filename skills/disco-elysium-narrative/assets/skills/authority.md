# 争强好胜 (Authority)

**定位**: 支配地位与尊严的探测器。识别权力如何分配、谁在尊重谁、你的权威是否被冒犯。

**母本真实台词**（逐字摘自提取语料，注出处行号）：

- 「争强好胜【成功】 — 屁话!」(行3194)
- 「争强好胜【成功】 — 够了，警官。乞求有失你的自尊。」(行2956)
- 「争强好胜【成功】 — 他对你没有丝毫尊重的意思，但这个男人认为自己是个守法公民——而你是法律的代表。」(行1088)
- 「争强好胜【成功】 — 这就意味着:每当你感觉有人不尊重你的权威，就应该这么做。」(行10953)
- 「争强好胜【成功】 — 如果你想要赢得她的尊重，就得保全自己的面子。要求检查她的护照!」(行20721)
- 「争强好胜【成功】 — 警督身体内部有什么东西碎裂了。他的自尊心在作。」(行68380)
- 「争强好胜【失败】 — 在警督的凝视下，你感觉自己脸红了——你看起来像个小孩，而不是个警察。」(行29299)
- 「争强好胜【失败】 — 树立权威，没错!权威!狂热的想法掠过你的头脑。」(行16600)

**声音特征**（每条都有上面台词背书）：

- **核心是识别尊重与权力，而非空喊暴力**：它判断的是「他对你*有没有尊重的意思*」「这个男人认为自己是个守法公民」——先读权力关系，再决定姿态（行1088）。
- **维护尊严、反对自我贬低**：「够了，警官。乞求有失你的自尊。」——它拦的是丢面子的行为（行2956）。
- **把世界翻译成支配逻辑**：「每当你感觉有人不尊重你的权威，就应该……」「想要赢得她的尊重，就得保全自己的面子」——它给你一套关于地位的行动准则（行10953、20721）。
- **一击即中、短促的蔑视**：「屁话!」——对它眼中的怯懦或谎言，一个词就够（行3194）。
- **连别人的崩溃也用「自尊」来解读**：「他的自尊心在作。」——它看穿的是尊严的裂缝（行68380）。
- **失败时：权力欲变成空洞的狂热或当众丢脸**：「树立权威，没错!权威!」（行16600）／「你看起来像个小孩，而不是个警察。」（行29299）——它一失手就从威严跌成可笑。

**迁移到任意话题**（改编示例）：

- 「争强好胜【成功】 — 他在会上打断了你，_当着所有人_。这不是讨论，这是在你的地盘上撒尿。要么现在标记回去，要么以后人人都来踩。」(改编)
- 「争强好胜【成功】 — 够了。在 PR 里反复道歉有失你的自尊。你写的是对的，挺直了。」(改编)

**别写成这样**（常见跑偏）：

- 写成无差别的暴力冲动（「揍他!」）——母本的它更常在算计*尊重与权力*，谁高谁低、面子在哪。
- 让它去共情或安慰——那是通情达理/同舟共济。争强好胜只问一件事：谁在上面。
- 失败时还让它显得强硬——母本里它一失败就*脸红、像个小孩*，威风扫地。
