# Assets 使用指南

## 目录结构

```
assets/
├── skills/          # 24个技能的详细风格指南（含真实游戏台词）
│   ├── intellect.md   # 智力类: 逻辑思维, 博学多闻, 能说会道, 故弄玄虚, 标新立异, 见微知著
│   ├── psyche.md      # 精神类: 平心定气, 内陆帝国, 通情达理, 争强好胜, 同舟共济, 循循善诱
│   ├── physique.md    # 体格类: 钢筋铁骨, 坚忍不拔, 强身健体, 食髓知味, 天人感应, 疑神疑鬼
│   └── motorics.md    # 身手类: 眼明手巧, 五感发达, 反应速度, 鬼祟玲珑, 能工巧匠, 从容自若
├── examples/        # 完整叙事范例
│   ├── life-decision.md      # 人生决策场景
│   ├── technical-problem.md  # 技术调试场景
│   ├── financial-choice.md   # 金融投资场景
│   └── game-elements.md      # 游戏特有元素集合（含物品对话、闪切、政治暗流等）
└── templates/       # 可选交付模板
    └── narrative.html        # 沉浸式暗色单页（HTML 网页版输出，细节以 SKILL.md 为准）
```

## 使用方法

### 1. 必须先读技能风格指南

每个技能有独特的声音——**不能凭印象编写**。写作前必须读对应的 skills/*.md 文件。

> 每份指南分两层:**「母本真实台词」是游戏原文**(摘自简体中文游戏文本,带出处行号,用来校准用词与句法,可直接借鉴风格);**「迁移示例」是为现代话题改编的**,已标注"(改编)",非游戏原文。别把改编层当成原作来引用。

关键的不可替代特征:
- **故弄玄虚**: 自称"吾辈"，称玩家"大人"/"陛下"
- **同舟共济**: 电影式闪切到其他地点的场景
- **天人感应**: 永远伴随物理性的寒冷/颤栗
- **五感发达**: 必须标注感官类型 `(视觉)/(听觉)/(嗅觉)/(味觉)`(母本里"触觉"几乎不带标注，需要触感直接写裸句)
- **内陆帝国**: 让物品作为独立对话角色说话
- **钢筋铁骨**: 粗犷直白、用"兄弟"称呼;本质是原始生存本能，在特定情境会滑向法西斯式的"相信直觉"——引用那层内容要带语境，别把"钢筋铁骨=法西斯"当成它的常态标签

### 2. 根据主题选择技能组合

每个叙事需要4-6个技能，且**必须包含至少一对冲突技能**。

完整的「主题 → 推荐技能 → 核心冲突」对照表见 **SKILL.md 的 `Topic Adaptation` 一节**(以那份为准,避免两处各写一份导致漂移)。

### 3. 参考相似场景的范例

- 人生重大决策 → `examples/life-decision.md`
- 技术/编程问题 → `examples/technical-problem.md`
- 金融/投资选择 → `examples/financial-choice.md`
- 特殊游戏元素 → `examples/game-elements.md`

### 4. 特殊元素使用时机

- **古老的爬虫脑 + 边缘系统**: 讨论放弃、虚无、死亡冲动、彻底的疲惫
- **物品对话**: 当叙事涉及用户面对的物品（屏幕、手机、咖啡杯）时，给它们声音
- **同舟共济闪切**: 展示其他人（同事、朋友、家人）在远方的行为，建立连接感
- **天人感应**: 需要环境氛围和超自然感的时刻，永远伴随寒冷
- **失败检定**: 至少包含1-2个失败检定，它们揭示角色弱点，让成功更有意义
- **"你 —" 玩家对话**: 必须穿插在技能检定之间，创造节奏感

## 核心原则

1. **先读后写** — 不读技能风格指南不写作
2. **冲突即叙事** — 没有技能冲突就没有好故事
3. **失败很重要** — 不要只展示成功的检定
4. **玩家有声音** — "你 —" 是节奏的关键
5. **物品会说话** — 内陆帝国让世界活过来
6. **简洁为上** — 短句、留白、具体细节
7. **不确定性是美德** — "没有人知道"比"答案是"更诚实
