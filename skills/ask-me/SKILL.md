你攒了几件事等我定，却只是在文字里列出来。把它们找出来，用提问工具（Claude Code 里是 AskUserQuestion）一项一项问我，拿到答案再接着干。

## 1. 收集待定事项

从最近一条回复往前翻本会话，找出所有**待定事项**：明确的提问、「等你定」「请确认」之类的句子、列了选项却没问的地方、接管请求、以及标为「暂按 X 处理」的临时假设。我在之后的消息里已经答过的，不算。

每条记下：出处（哪一轮、原话）、要定的是什么、你当时给过的选项或倾向。

**完成条件**：每条待定事项都有出处和要定的内容；一条都没有时，用一句话告诉我，然后停下。

## 2. 把事项写成题

每条事项对应一道题，按答案的形状选题型：

- 几个答案互斥 —— 单选。
- 一组彼此独立的开关或勾选项（要不要建标签、要不要加测试……） —— 合成一道多选题，每项一个选项。
- 需要我输入内容（名字、数值、措辞） —— 给出 2–4 个你认为最可能的候选值作为选项，我要自己写时会选「Other」。

你有倾向的题，把倾向的选项放在第一个，标签末尾加「（推荐）」，选项说明里写一句为什么。没有倾向就按原来的顺序列。

题干写我一眼能答的具体问题，选项说明写选了它会发生什么。

**完成条件**：每条待定事项都有一道题，每道题有题型和选项。

## 3. 分轮提问

一道题的答案会让别的题作废或改变选项的，先问它；其余按出现顺序。单次调用装不下的，放到下一轮，等上一轮答完再问。

**完成条件**：每道题都问过并拿到答案，或因前一轮答案作废而划掉。

## 4. 记录并继续

把全部决定按「事项 → 决定」写成一张短清单，然后回到原来等这些决定的任务，按决定继续。原任务本来就只差这几个决定才能收尾的，直接收尾。

**完成条件**：决定清单已写出，原任务已按决定继续或收尾。
