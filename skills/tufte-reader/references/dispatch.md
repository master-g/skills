# 分章派发

每章由一个子 agent 写成**片段**（一个完整的 `<article class="chapter">`），主 agent 把片段按原文顺序拼进页面。子 agent 看不到主对话，它需要的东西全部写进交代里。

## 写好外壳

派发之前，在页面里写好扉页（含 `<title>`）和参考文献，示例章 `<article class="chapter" id="ch-1">` 原样留着。子 agent 拿这个页面的副本试构建：`<title>` 还是骨架占位、或者引用链到的文献条目不在页面里，构建都报 ERROR。

## 切原文

把原文按章切开，存成工作区的 `source/NN-<章 id>.*`（`NN` 是两位序号，章 `id` 按 [标记契约](markup.md) 的「章与节」取）。该章用到的图文件留在输出目录的 `figures/`。原创撰写没有原文可切，改为把该章要用的资料路径列进交代。

## 派发

一批派四个子 agent，一批全部返回后再派下一批。每个子 agent 的交代写全这几项：

- 任务：把这一章写成片段，存到工作区的 `chapters/NN-<章 id>.html`。
- 处理方式：全文忠实翻译、整理或原创撰写，以及用户对这本读本的特别要求。
- 路径：该章原文（或资料）、`glossary.md`、`figures/`、写好外壳的页面、`references/markup.md`、`references/style.md`、`scripts/`，都写绝对路径。
- 该章在结构清单里的那几行：章 `id`、`chapter-number`、各类元素的条数；原创撰写再加图、表、式的编号区间。
- 画图：用图元库的图，画图代码写到 `chapters/NN-<章 id>.figs.py`，只往 `FIGS` 里加条目，键名以章 `id` 开头；片段里留 `<!--FIG:键名-->`，占位符由主 agent 统一填。
- 完成标准：片段的段落、脚注、图、表、公式与该章原文一一对应；试构建 0 个 ERROR，统计与该章清单的每处差异都说得出原因。试构建的做法：把页面复制成同一目录下的 `<页面名>.NN.check.html`（图片路径相对页面所在目录解析），用片段替换示例章，有占位符时在这个副本上用本章的画图脚本 `embed`，构建，核对完删掉副本。
- 返回：片段路径；构建统计与清单的差异及原因；`glossary.md` 之外自己新定的译名；存疑之处（取不到的图、拿不准的译法）。

## 拼接

一批返回后先收术语：把各章新定的译名并进 `glossary.md`，同一术语出现两个译名时定下一个，在已有片段里统一替换，后面各批用更新后的术语表。

全部返回后：

1. 在同一个进程里依次执行各章的 `.figs.py`，再用 `embed` 填回占位符。全书的图在一个进程里画完，图内 `id` 的前缀才各不相同。
2. 按 `NN` 的顺序把片段替换掉页面里的示例章，接在扉页之后、参考文献之前。
3. 通读各章之间的指代（「见第 N 章」「如图 N」「式 (N)」），对不上的改正。

之后回到 SKILL.md 的「构建与核对」，对整页构建，统计与全书合计对账。
