# URL to Kami

读取网页材料，使用已安装的 Kami 模板生成中文文档。仅阅读、总结或保存原始文字的请求不触发排版。
用户已明确选择交付格式、语言或输出目录时，沿用其选择。

## 前置依赖

从当前技能目录清单定位 `kami` 并读取其 SKILL.md；不要假定固定安装路径。
Kami 不存在时，说明缺少排版模板与构建契约，可完成已授权的正文提取，排版部分标为受阻。
不自动安装技能，也不把其他设计系统的产物冒称 Kami。

## 获取材料

优先复用会话中已取得的完整正文；否则使用用户指定或当前可用的提取工具。

- X/Twitter：读 [X 提取](references/x-extraction.md)，委托可用的 x-to-markdown。
- arXiv 全文：读 [论文提取](references/arxiv-extraction.md)，区分摘要页与 PDF 正文。
- JS 页面：普通提取失败时读 [JS 页面提取](references/js-rendered-sites.md)。
- Substack 图片：确实需要保留图片时读 [图片提取](references/substack-image-extraction.md)。
- 普通网页：用可用正文提取工具；需要登录或渲染时使用当前浏览器工具。不要依次试完历史工具清单。

核对标题、作者、日期、正文完整性及必要图表。登录墙、摘要、截断文本不能当全文。
无法取得所需正文时报告缺口；不要用模板或猜测补齐。提取结果同时用于多个交付物时复用原始文本，不从生成 HTML 反向剥离。

## 排版与输出

- 默认简体中文，保留代码、标识符、专有名词和有分析价值的原文引句。遵守当前环境的转载限制。
- 按用户要求决定全文转换、摘要或导读，材料长度不足以授权自动改变交付范围。导读明确标注已阅读与未阅读范围。
- 单篇长文使用 Kami 的 `long-doc`，短材料使用 `one-pager`；具体模板以已安装版本为准。
- 保留作者观点及数据来源，文档附原始 URL。只加有材料支撑的章节、引句和图表。
- 按 Kami 实际模板与构建用法生成文件。默认 HTML + PDF；PNG 仅在用户要求图片时生成。
- 输出到用户指定目录，否则用 `~/Downloads/<slugified-title>`。已有同名文件时保留原件，使用新名字。

仅在 macOS 构建遇到相应错误时读 [构建排错](references/macos-build-notes.md)。
不为一次排版修复整套系统依赖，不把脚本退出 0 当成视觉验收。

## 完成条件

打开实际 HTML/PDF，核对中文字体、分页、代码与表格裁切、图片和来源链接。
交付已验证文件的路径，说明正文覆盖范围、构建回退及未完成的格式。
HTML 已生成但 PDF 构建失败时继续处理授权范围内的可行回退；仍失败则明确交付部分结果。
