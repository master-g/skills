# sharpen 评测

三个用例，每个一句意图加一个本机夹具仓库，无人值守运行（走技能里没有提问工具的分支），产出的 prompt 按 9 条断言评分。工作区（`iteration-N/<case>/{old_skill,with_skill}/outputs/`、`grading.json`、`timing.json`、下游实跑副本）放在 `/tmp/sharpen-workspace/`，不进库。

## 用例

| 用例                 | 意图                               | 夹具                                                           | 用例专属断言                                                                   |
| -------------------- | ---------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `rust-formal-proofs` | 给这个项目的逻辑核心增加形式化证明 | `/Users/mg/github/bpe-tokenizer`（Rust，函数体全是 `todo!()`） | 解法点名具体验证工具并给依据；验收含该工具的调用命令                           |
| `ts-cold-start`      | 优化这个项目的冷启动耗时           | `/Users/mg/github/pi-wingman`（TS，pi 扩展，jiti 加载）        | 先探索或验收含具体测量命令；验收至少一条数值阈值或相对基线百分比               |
| `c99-fuzzing`        | 给这个项目加上模糊测试             | `/Users/mg/github/tobi`（C99/CMake）                           | 解法点名具体 fuzzer 及 CMake 接入方式；验收含 sanitizer 构建与 fuzzer 运行命令 |

五条通用断言：七个槽位齐全（01）、目标点名的路径真实存在（02）、验收每条可检查（03）、块内 prompt 自足（04）、块外列出放弃候选（05）；另两条通用断言是未核实事实标「待验证」（08）、验收与约束互不冲突（09）。断言文件在各用例的 `graders/`。

## 基准

`old_skill` 是提交 8eb367d 时的 SKILL.md（无人值守分支与交接步已在其中），`with_skill` 是按第一轮运行笔记改写后的版本。每个用例各跑一次。

| `c99-fuzzing`        | 9/9            | 112,481 | 580 | 9/9             | 116,162 | 619 |
| `rust-formal-proofs` | 9/9            | 97,861  | 546 | 9/9             | 86,616  | 484 |

| 合计                 | 27/27          | 311,511 |     | 27/27           | 299,940 |     |

两轮断言全过，断言在 n=1 下没有区分度：基线版本已经要求七槽位、可检查验收和自足，断言正是围绕这些写的；基线快照取在无人值守与交接两处修复之后，所以这两处修复的效果没有进入对照。改写带来的差别出现在断言之外：既有禁区进了约束槽位、多处「待验证」标记、交付物布局自成一段、`ts-cold-start` 改选打包方案并附实测探针，与夹具 AGENTS.md 的冲突作为默认取舍明示给用户。

改写依据是第一轮三份运行笔记里对正文的意见：项目指令文件要映射进约束与停下时机、`docs/` 只读索引与 ADR、可测量意图先量基线、目标未实现时交付物改层、来源由近及远、候选带冲突检查、阈值要有依据、环境前置不占题、七槽位之外允许加段、成稿后自检冲突、环境事实只写查起来贵的、停下时机含改本机环境的安装。

评测后的 SKILL.md 比 `with_skill` 快照多三处澄清（目标不是瓶颈时的处理、阈值依据全缺时写「首次实测后定」、放弃候选逐个说明），没有再跑一轮。
