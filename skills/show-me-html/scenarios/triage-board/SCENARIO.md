## 冻结材料（mock 工单 12 张）

三列初始状态：现在修 4 张、本周修 5 张、观察 3 张。

现在修（P0/P1）：

- 支付回调签名校验失败（支付，P0，#4415）

- 告警风暴：同一规则 5 分钟 200 条（监控，P1，#4417）

本周修（P2）：

- 导出 CSV 列序不稳定（报表，P2，#4390）

筛选要求：按领域（网关 / 支付 / 前端 / 监控 / 任务 / 报表 / 后台 / 集成 / 基础设施 / 安全）
与优先级（P0–P3 / 待复现）两维过滤，计数回显随拖动更新。

## 通过标准

- build.py ERROR = 0
- 拖拽可用，键盘 ← → 可在列间移动（无障碍替代路径）
- 列计数随拖动实时更新；`hidden` 的卡不进导出
- 顶部「复制为 Markdown」导出的是筛选后的状态
- 无新增导出按钮（骨架已覆盖，不重造）
