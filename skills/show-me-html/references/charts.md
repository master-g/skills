# charts.md — 数据图规则与图型目录

材料里有数值序列、类目量、占比、分布、网络或流向时按这份文件选图、画图。
它只管**数据图**；关系与结构的示意图（架构、流程、时序、状态机）走 `diagrams.md`，
图外的 figure 外壳见本文「五件套」。三者共用同一套 token 与运行时。

来源：`larashero3-dotcom/lieflat-charts` 的图型体系与选型规则（2026-09-06 读取），
颜色、字体、外壳和运行时已换成本 skill 的；所有渲染只用 SVG 与页内 JS，零外部依赖。
gallery 里 37 个块是上游代码的衍生（PolyForm Noncommercial 1.0.0），名单与全文见 `../assets/gallery/LICENSE-lieflat-charts.md`；交付页复制这些块时同样受该许可约束。

## 什么时候画数据图

- **表格能讲清的不画。** 六个数以内、读者只需查数不需比较形状时，用表。
- **一句话能答的不画。** 一个 KPI 直接写进正文或指标带。
- 数据形状含时间、比较、构成、分布、关系、流向之一，且读者要从形状里读判断，才画。

## 工作流

每次都走这六步，写进合成前的 2–3 句计划里：

1. **判数据形状**，不问用户要什么图。几个类目的比较？带时间的序列？占比？带正负？多对一归属？网络？逐条记录的分布？形状是选图的主键。
2. **先审计基础型与编辑型。** 按形状从下方决策树取候选，至少比较 3 个（不足 3 个列全部）：语义是否诚实（每个点、档、刻度背后有真实单位或明确口径）、视觉是否装得下（标签、密度、阅读时间）、叙事是否承载判断。
3. **只在必要时进快读型。** 前两组都不合适，或用户明确要 dashboard、监控、周报、演示、三秒快读，才看 G 系；记下为什么前两组不行。
4. **锁定图型编号再组织整页**，每张图记录编号、gallery 文件与块名，以该块的结构和编码为骨架；不先想「这页讲六件事」再临时发明图型。
5. **按图数规则组批次**：一图一结论，去重后定数量，同页图型不重复、轮廓轮换。
6. **渲染并自检**（本文末尾清单）。改数据不改模板的核心几何、编码与动效。

## 图数规则

数量由独立结论数决定，不由数据列数决定：

| 请求类型                     | 默认数量 | 规则                                       |
| ---------------------------- | -------: | ------------------------------------------ |
| 单个问题 / 单张表 / 一个指标 |        1 | 只交付最强的一张                           |
| 两到三个明确结论             |      2–3 | 每张承担一个不同结论，可共享数据源         |
| 一篇文章、论文或完整案例     |      4–6 | 覆盖总览、构成、比较、关系或变化等不同形状 |
| 用户明确要求数量             |   按要求 | 仍删重复图；撑不起就少做并说明             |

单页上限 6 张，超过拆页或分节。一页多图至少一张总览，其余必须提供新维度。两图同一结论只留更诚实的那张。

| 家族             | 编号   | 基本单元                 | 线条 | 读法       | 场合                        | 文件                               |
| ---------------- | ------ | ------------------------ | ---- | ---------- | --------------------------- | ---------------------------------- |
| 基础型 Basics    | F1–F17 | 熟悉的图型剪影，单位可数 | 发丝 | ~30s       | 数据只有几个类目或几十天    | `../assets/gallery/basics.html`    |
| 编辑型 Editorial | L1–L20 | 一点一记录，拒绝聚合     | 发丝 | 30s+       | 年报、长文、海报、README    | `../assets/gallery/editorial.html` |
| 快读型 Glance    | G3–G22 | 提前聚合的形状           | 2px+ | <10s       | dashboard、周报、监控、演示 | `../assets/gallery/glance.html`    |
| 交互大图 Big     | B1–B3  | 一图一卡，整页幅面       | —    | 必须 hover | 节点或路径多到静态读不出    | `../assets/gallery/big.html`       |

**默认顺序：编辑型 → 基础型 → 快读型。** 没有明确场合时禁止默认快读型。
主力是 L1–L15 与 F1–F13；L16–L20、F14–F17、G19–G22 是后备，只在主力无法诚实编码时用并写明理由。
例外：F13 树图、F15 箱线、F16 河流、F17 K 线、L17 日历热力、L20 平行坐标 —— 主力里没有对应编码，命中形状直接用。

**数据少不等于只能快读型。** 几个百分比摊回可数单位（1 点 = 1 人 / 1 百分点）就拿回了编辑型密度；
单位含义写进单位行，只摊诚实单位，四舍五入吃掉的写在底注，不凑假个体。
小数据图要配「家具」：账本横线、虚线导轨、每 5 或 10 单位的点标、旁注引线 —— 数据层诚实稀疏，密度预算花在家具上。

## 动态图型

动效只在**数据形状本身含时间推进**时使用，四种形状各对应一张：

| 形状           | 图型                | 实现                                        |
| -------------- | ------------------- | ------------------------------------------- |
| 排名随时间演变 | G16 条形赛跑        | 行位置与条长走 CSS transition，每 1.2s 推进 |
| 实时滚动序列   | G17 实时流          | 滑动窗口，每 300ms 重绘                     |
| 累计增长的揭示 | G18 一笔画 + 计数器 | 描线、面积裁切与大数由同一个 rAF 驱动       |
| 多类目入场节奏 | G12 交错波          | 逐根 36ms 弹入                              |

此外 G9 每 3s 轮播视图。规则：

- **滚入视野才播，重播按钮重来**（运行时 `reveal` 负责，循环定时器登记在 `keep` 里，重播前清掉）。
- **`prefers-reduced-motion: reduce` 下必须有末帧**：静态图型靠 CSS 关动画；循环图型看 `motion` 标志直接画末帧，不起定时器。
- 入场动画快进快停：点阵 8–15ms/个、条形 80–130ms/根，不弹跳（波浪入场例外）。
- **动画不可优于结构**：需要发明新布局才能安放的效果不做。
- 动效编码论点：方向、次序、速度对应数据；纯装饰的动效删掉。

## 交互三问（静态还是可交互）

1. 这根线 / 点背后有没有真实记录？没有（纯肌理，如 L6 的辐条、L13 的淌线）→ 不加交互。
2. 有记录 → 不点能不能读出来？元素 <50 且两端有标注 → 静态够用，hover `<title>` 是锦上添花。
3. 元素 >50 或多段路径 → 必须 hover / 钉住（B1–B3）：可见线下垫 9px 透明孪生线当热区，hover 单线亮整条，hover 标签拉整束，点击钉住，点空白释放；键盘可 Tab 到节点，focus 等同 hover。

## 硬规则（违反即返工）

**颜色**

- **明度即数据**：最重要 = 最重（`--chart-1` / `var(--ink)`），多系列沿 `--chart-1…5` 或 `--ink-90…22` 按重要性分配，不按出现顺序随手拿。
- **一律实心**：不透明材质、不发光、不渐变、无阴影。唯一例外是叠加型图（L10）里透明度本身编码密度。
- **一张图一个主角** `var(--chart-hero)`：峰值、当前值、改版后、最大增幅、答题的那一段。主角可以是一个元素或回答标题的那一组（L14 最大簇、G4 最大来源）；面积已经很大的元素（F13 最大叶子）改描橙边，不整块涂橙。第二处上 hero 等于没有主角。
- 分类色 `data-tone` 只给真的平级类目，同页 ≤4；类目 >6 退回明度阶。

**形状与数值**

- 数值与视觉严格成正比；面积编码用 `Math.sqrt(v)` 换算半径，不拿数值直接当半径。
- **柱状图不断轴。** 极端值：让它冲天（最诚实）、主图 + 放大镜小图、或撕柱不撕轴并明说画不下。
- 柱端胶囊圆角（竖柱圆上端、横柱圆外端）；卡片无边框，靠面色分卡。
- 花瓣皮只给等分或近似等分的径向图。

**文字**

- 图内数值、轴标签、单位行、来源行走等宽字体（`.fig svg text` 默认）；类目名可加 `class="name"` 用正文字体。数值字重 600，不用 700/800。
- SVG 最小字号：半宽卡 6.5px、通栏 5.5px。装不下改 `<title>` hover 出，不缩字号硬塞。
- 标题写结论不写图型名：「免费档撑起一半月收入」可以，「柱状图」不行。
- 单位行把图例说清（「一档 = $1k · 空心 = 周末 · 主角 = 峰值」），读者不看代码只看这一行。

**数据**

- 演示数据用运行时 `rnd(i, k)` 确定性伪随机，禁用 `Math.random()`；刷新必须长一样。
- 峰值标签强制最小间距（邻近峰值只标一个）。
- 只摊诚实单位；没有的数据不编。

## 什么时候说不

- 断轴柱状图 → 拒绝，给三个诚实方案。
- 发光 / 玻璃拟态 / 3D / 渐变 → 拒绝。
- 多色相画单序列 → 拒绝，用明度阶。
- 类目 >6 还要分类色 → 拒绝，退回明度阶。
- 给纯装饰元素加交互 → 拒绝并解释。
- 雷达图 → 不做，改表格或 F5 / L7。
- 数据太少撑不起所选图型（3 个节点要力导向）→ 降级到更简单的图并说明。

- `data-chart` 写图型编号；页面有它 `build.py` 才内联运行时。

- 通栏图加 `class="fig wide"`；多图放进 `<div class="charts">` 栅格。
- `<title>`/`<desc>` 留在 svg 里，重播时运行时只清图形。
- 需要状态栏（B3）加 `<div class="fig-status" data-md-skip><span data-text></span><span data-pin></span></div>`，用 DOM 构造内容，不用 `innerHTML`。
- 半宽卡 viewBox `0 0 400 320`，通栏 `0 0 800 320` 起；宽高比由 viewBox 决定，svg 宽 100%。

## 库外图型

用户要的图不在目录里（或发来一张参考图）时，现场造句：

1. **先回答本体**：每个视觉通道（位置 / 长度 / 角度 / 面积 / 明度 / 密度）分别对应哪个数据维度；答不出就问数据结构。抄形不抄魂等于白做。
2. **找最近的亲戚**：目录里数据形状最像的一张当起点，继承布局骨架与动画节奏。
3. **用 token 造句**：颜色、字体、圆角、动画参数全部从系统拿，产出和库里的图一眼一家人。
4. 过硬规则与自检，与库内图同一标准。

## 交付前自检

1. 数值和视觉成正比？面积用了 sqrt？柱没断轴？
2. 颜色只有 token？非 ladder 颜色即返工；hero 只出现在一处？
3. 标签会不会重叠？邻近峰值只标一个？
