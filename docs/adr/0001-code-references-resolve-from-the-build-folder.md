# show-me-html 的代码引用按运行构建的目录解析路径

show-me-html 的**代码引用**（`<pre><code data-src data-lines>`）按运行 `build.py` 时的当前目录解析路径，只能读这个目录以内的文件；本地图片则按页面所在目录解析。2026-11-17 的设计问答定下这样做，理由有三条：

- 来源标注直接显示作者写的路径。Agent 一般在仓库根目录运行构建，路径就是读者熟悉的仓库相对路径（`src/app.ts:18-30`）。
- 页面常存到仓库以外（如 `/tmp`）。按页面所在目录解析时，路径得写成一长串 `../`，标注也会把这些带进成品。
- 运行目录同时划定了可读范围，越界、绝对路径和 `~/` 一律报错，写错的路径读不到仓库以外的文件。

图片保持按页面所在目录解析，因为直接在浏览器里打开未构建的页面，看到的也是那张图；而且图片只在第一次构建时内联一次，之后不再读文件。

## Consequences

- 代码引用每次构建都重读文件，所以重建要在同一个目录里运行。换了目录、文件找不到时，保留页面里已有的代码并给 WARN；换的目录里恰好有同名路径时，会读进那个文件，构建器分辨不出来。
- 以后若改成按页面所在目录解析，已经写好的代码引用会整批失效，所以这条规则轻易不改。

## Considered Options

- **按页面所在目录解析**（和图片一致）：页面在仓库以外时路径和标注都要写 `../`。没有采用。
- **允许绝对路径**：成品会泄露本机目录结构，可读范围也没有边界。没有采用。
