# show-me-html 代码引用：已定的设计决定

2026-11-17 的设计问答（grill-with-docs）里定下的事项，用户的选择与当时的建议全部一致。这是写规格（`/to-spec`）的输入，规格写成 issue 后以 issue 为准。

**代码引用**是构建时按作者给出的路径和行号，从仓库文件里读进页面的代码块；**示意代码**是作者手写、不对应某个文件某几行的代码块。两个词的定义在 [show-me-html 术语表](../../skills/show-me-html/GLOSSARY.md)。

## 决定

| 事项       | 决定                                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------------- |
| 推进方式   | 先 `/to-spec` 写规格，再 `/implement-spec` 实现                                                                      |
| 写法       | 沿用 `<pre><code>`，加 `data-src` 和 `data-lines` 两个属性，内容留空、由构建器填；复制与换行工具条、语法高亮照常工作 |
| 路径       | 按运行构建命令的当前目录算，只能读这个目录以内的文件；`../` 越界和绝对路径都报 ERROR                                 |
| 显示       | 带行号，从文件里的实际行号开始，行号不进复制和 Markdown 导出；第一版不做高亮行                                       |
| 安全和长度 | 拒绝存放密钥的文件和目录、含令牌的文件、二进制文件；超过 200 行报 ERROR，超过 40 行给 WARN；行号超出文件末尾报 ERROR |
| 重复构建   | 每次构建重读文件刷新内容；找不到文件时保留页面里已有的代码，只给 WARN                                                |
| 强制程度   | 只改文档推荐代码引用，手写的代码块（示意代码）不报错                                                                 |
| 术语       | 「代码引用」「示意代码」，收在 show-me-html 自己的术语表                                                             |
| 细节默认   | 来源标注写成 `src/app.ts:18-30`，生成在代码块上方；单行写 `data-lines="18"`；不写 `data-lines` 时引用整个文件        |
|            | 不写 `language-*` 时按扩展名推断，扩展名没有对应语法时按纯文本处理                                                   |
|            | 带 `data-src` 的代码块不许手写内容；diff 代码块不支持 `data-src`；只写 `data-lines` 不写 `data-src` 报 ERROR         |

## 写规格时要补的一条

「带 `data-src` 的代码块不许手写内容」和「每次构建重读文件刷新」放在一起有缺口：第一次构建后代码块里已经有内容，第二次构建时分不出是填进去的还是作者手写的。规格里补上：构建器填完内容后在代码块上留一个标记，带标记的重建时直接刷新，不带标记却有内容的才报 ERROR。读者看到的页面和报错行为不变。

## 待用户决定

- 「路径按构建目录算」要不要写一份决策记录（`docs/adr/0001-…`）：它和本地图片的路径规则不同，而且页面用多了再改规则会让旧页面失效。当时的建议是写，在写规格时一并起草；用户还没答。

## 背景事实

- 技能默认把页面存在工作目录，也就是 Agent 所在的仓库，构建命令通常也在那里运行。所以按页面所在目录算和按运行构建的目录算，默认是同一个目录；只有用户把页面放到别处（如 `/tmp`）时才不同。
