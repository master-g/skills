# 任务定义样张

Type: prototype
Status: open
Blocked by: 05, 06, 08, 09, 10
Map: [地图](../map.md)

## Question

一个任务文件长什么样？为三类场景（SWE、产出物、标准答案）各做一份粗糙样张：给选手的提示词、起始状态（repo@commit 或资料包；代码审查是截取后的引入提交，见「[标准答案类评分](10-grading-reference.md)」）、环境与超时、评判依据（隐藏测试 / rubric / 参考答案；产出物类还有评委核对事实用的资料包，见「[产出物类评分](09-grading-artifacts.md)」）、所属场景与版本号，让用户对着样张定字段。样张作为资产链接在本票，不进 `bench/`。
